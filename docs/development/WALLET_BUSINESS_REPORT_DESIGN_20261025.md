# 钱包收银台营业报表

范围：新增独立营业报表与收银台、更多入口，参考每日营业报表的期间选择、明细和合计。保留现有对账报表，不改交易、余额或日账产品。

方案：复用钱包交易记录投影，在数据库中完整聚合，不分页拉取交易再相加。日看单日，月按日，年按月；按门店时区和实际记账时间统计，仅纳入 completed，待核实、取消记录不计入。消费、充值本金/赠送/权益、退款、赠送冲正和积分独立展示，不构造混合“总营业额”。收款科目按实际收款快照分组，消费外部收款与充值收款分开，属于各业务子项，不能与消费/充值再次相加。

实际发生过的项目按交易笔数判断显示，而不是仅根据合计是否非零；未发生项目隐藏。无交易期间显示空态。CSV 与屏幕口径相同。日期与时区由后端返回，切换查询立即清除旧结果，阻止旧请求覆盖新门店结果。

按用户补充，支持大项过滤：全部、消费、充值、退款与冲正、积分。大项入口仅在当前期间有数据时显示。表格、合计、CSV 同步过滤；更换期间后原大项无数据则回到全部，不保留不可见选项。退款按原业务区分消费退款、充值退款，但统一归入退款大项。

API：GET /api/v1/stores/{storeId}/wallet/business-report?period=day|month|year&date=YYYY-MM-DD。date 为所选期间内的日期。返回 period/startDate/endDate/timezone/currency 和 rows[{bucket,metric,channelName,amount,count}]。金额单位分，积分单位分值。年报限制自然年，不任意跨年查询；严格 ISO 日期、1900–9999 年，未知参数拒绝。无分页截断。private,no-store。

权限：沿用 wallet.reconcile.view 和 WalletAccess.staff 的只读历史访问规则；租户来自已登录身份，门店必须授权，平台身份禁止。积分仅在 wallet.points.view 存在时返回。无写接口、迁移、新权限、产品依赖或生产发布。

测试清单：日/月/年与闰年及门店午夜边界；按实际完成时间、不计待处理/取消；收款渠道、本金赠送分离；相同业务多证据不重复；跨租户/门店排除；零净额有交易仍展示；空态；权限拒绝；只读历史不受新交易 AppGate 限制；界面期间切换、错误清空、CSV 安全转义。使用 pointer PostgreSQL 隔离测试 schema。
