# 存酒报表日期格式修复（2026-11-03）

## 问题与改动

截图中的 yyyy-mm-日 来自原生 type=date 对浏览器区域语言的分段占位符渲染。不能靠 placeholder 或仅修改 lang 稳定统一显示，因此将本报表日期字段封装为独立控件：可见文本框明确显示中文“年-月-日”、英文“YYYY-MM-DD”，选择后显示 YYYY-MM-DD；右侧保留原生日期选择器，双向同步同一查询值。原生字段有独立可访问名称，键盘聚焦有可见提示。

开始、结束日期框等宽，沿用报表过滤面板、输入及按钮样式；窄屏下日期区域按需单列，未修改其他页面宽度。查询仍提交原有 from/to ISO 日期，不转换时区。手输新增格式和真实日历日期校验，拒绝非法日期、无效闰日、错误分隔符和反向区间；空值、重置、分页与原日期上下限继续有效。没有后端、接口、依赖或数据库改动。

## 验证与审查

133 项存酒组件回归通过，覆盖文本输入/原生日期值同步、中英文提示、清空、查询参数、无效日期及有效闰日。类型检查及完整前端构建通过。Code/UI review APPROVE，前端发布 GO。

使用只读合成账号页面验证，而非生产真实业务。IAB 桌面 CSS 视口 1214px（client/scroll 均1196px），两个日期框均353.35px；窄屏实际CSS 391px、321px，client/scroll 分别372/372、302/302，无横向溢出，日期框完整可读，中英文截图已保存。实际输入、原生日历字段值同步、查询和重置已验证。Chrome DOM 核对两个日期值及原生控件存在通过，但截图 API 两次超时，因此不声称 Chrome 截图或原生弹出日历视觉验收通过；实体手机、微信和生产真实账号交互未验收。
