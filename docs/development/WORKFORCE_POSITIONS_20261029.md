# 岗位目录本地实现与验收

2026-10-29；D:\RPB；未提交、推送或部署。

## 行为

管理 → 岗位管理，可新增、编辑、启用、停用及删除。用户明确纠正后，顶部改为独立“管理”页，岗位管理与管理员授权是并列入口；岗位不再挂在管理员授权页面下。租户共用目录，由既有总部管理员维护；获员工管理委派的门店经理可以选择岗位，但不能修改目录。普通员工不能读取管理目录。未增加权限、订阅或产品入口白名单。

员工资料岗位改为下拉，可不设置。岗位有稳定ID；改名后当前员工资料显示新名称。停用项不可新分配，原员工可保留；任何员工引用的岗位禁止删除，未引用项采用软删除。所有写操作有版本及重试规则、租户锁和原子审计。并发修改不能覆盖胜出版本。

## 数据库与兼容

V092新增workforce_positions及员工position_id，同租户复合FK、有效名称唯一索引、版本/时间戳/启用及软删除约束。旧非空岗位按租户、去首尾空格及大小写合并回填；员工原job_title、版本、更新时间与冻结工资、付款不变。当前员工查询join目录名称；历史文字不重写。旧客户端jobTitle只能匹配已维护目录或保留历史原值，不能再写入任意岗位。

独立PositionDtos/Repository/Service/Controller和EmployeePositionSelection负责目录及选项校验；不把CRUD堆入员工服务。前端独立PositionList/positionText，复用workforce API、样式、状态和路由。
