## New / Changed / Fixed

- 预订排队、收款、储值钱包、酒水寄存、员工考勤薪资、日账本共六条产品线，统一声明后台业务、只读历史和原单受控处理路径。普通工作区在状态确认前不挂载，未开通、关闭、到期或读取失败时阻止网址直达；恢复有效后按现有可见页30秒刷新恢复。菜单可见开关与商业资格分别处理，不扩大动作权限。

- 公开预订的入口发现、context、新预约和管理员配置补商业门禁；停用时不显示日期、登录或提交表单，重新有效后恢复且保留同门店填写。跨店慢顾客响应隔离。预订历史、分享和原预约取消沿用既有规则；排队、现场入座、清洁等命令授权不变。

- 显式history=1只允许声明的只读路径，不授权新增、设置、冲正或API命令；存酒纠错草稿、旧回调及扫码handoff不能跨入历史视图。退款、有效卡权益、原收款会话及有效存酒受控领取继续服从各自原单规则。缓存收款展示失效卸载；关闭的日账本普通记录网址转入只读。
- 新增独立员工/工资历史页和11条精确GET历史路径，支持个人工资、考勤、管理公司工资、分段及补发。保留租户、门店、工资公司、员工和冻结来源门店边界；员工管理权不授予工资管理权。工资金额取冻结快照，考勤月页是非持久化历史查询投影，不触发刷新或工资重算。补发公司名称沿用现有公司目录，模型没有名称快照，金额及项目仍为冻结数据。

## Migration / Permission / Compatibility

无数据库迁移、订阅或真实权限配置写入，schema仍为 `127|127|0`。历史余额、积分、卡权益、存酒、交易、工资和考勤记录均保留。新增API合同见 `docs/api/2026-11-02-product-route-access.md`、`WORKFORCE_HISTORY_API.md`、`public-booking-commercial-access.md`。

工作区直达校验复用AppGate。workforce注册既有workforce.view历史资格；本地安全配置只加明确GET，不放行未知子路径或写方法。顾客不使用员工摘要。新租户开通已集成产品无需改入口代码；新增产品实现时须一次性按共享目录和入口同步技能注册业务/历史/原单路径，不能把任意GET默认为历史。

此前统一常用入口/二维码域名修复保留，本轮未改证书或nginx。统一系统分享域名无需逐户新增证书；另行绑定自定义域名不在此保证内。
