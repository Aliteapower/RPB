## 新行为

- 顾客及商户/员工共用紧凑商品列表：左实物照片或中性无图占位，右酒名、余量和减/数量/加，下方位置、标签及原快照到期说明。照片仍可放大；无图不会假造商品图片。同名不同存酒记录仍以itemId独立核对，不合并库存。
- 数量0表示未加入，调整数量自动计入本次取酒车，可进入车内移除或继续选择。车内直接显示最终批量清单，不再勾选、不再多一轮确认。最多50项沿用服务限制；取酒车仅在当前页面内存中保留，不写入顾客资料缓存。
- 顾客一次POST原/intents接口提交全部selections，生成一个整车二维码及明细；仍由店员核销后扣库存。原取消、过期、记录和未确定操作恢复保留，顾客不能自行扣库存。
- 商户员工一次POST原/direct-deliver提交当前customerId和全部selections，取酒车提示“提交即确认整车实物已交付，并一次扣减存酒”，按钮即最终交付动作，不弹第二个确认区。成功清空本次车；失败保留清单。原幂等、权限、库存事务和原单恢复保持。
- 自动刷新不会静默减少已选数量；库存不足、过期、消失或开瓶限制不符时整车提交禁用，必须显式调整。切店、换顾客、同店顾客身份变化清空旧车及行快照；成功提交后也清空。看图、加减数量和进入取酒车不触发命令API。
