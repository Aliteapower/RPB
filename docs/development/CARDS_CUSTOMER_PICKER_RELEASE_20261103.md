# 持卡核销顾客选择优化（2026-11-03）

## 行为与范围

`CardOperations.vue` 在手机号/姓名查询得到唯一顾客时立即选中，展示姓名、手机号及“更换顾客”“清空”。多条结果直接显示可点击结果，不自动猜测顾客；无结果给出提示。更换保留查询词并聚焦选中输入，清空同时删除查询词。两者清除卡、方案、数量、来源及当前请求/二维码，扫码识别复用同一选择流程。

持卡下拉区分未选顾客、加载中、暂无持卡和失败。失败可重试，错误不能伪装为无卡；唯一有效持卡自动选中，多卡保留选择。过期/未生效/撤销卡不能自动选中或用于出码。顾客无卡时明确提示先领卡或购卡，不因选了一个卡方案就允许对该顾客生成核销码；未指定顾客的原有按方案出码流程保留。免费领卡按钮遵循现有后端规则，仅允许有效集次卡方案，普通次数卡/月卡不能免费领取。

顾客查询、持卡加载及出码增加门店/选择版本检查，清空、更换门店或卸载后的旧响应不覆盖新上下文。API、后台权限、租户/门店范围、库存/核销/扣款规则和历史记录不变，不自动发卡或核销。
