# 租户共享顾客邮件配置（2026-11-03）

## 修复与行为

原独立邮件设置页复用预订后台接口，接口被 reservation_queue 商业权限拦截，造成仅开通存酒的租户看到“没有租户后台权限”。新增独立顾客邮件管理接口，保留旧路径作为兼容别名；预订业务及 OAuth 仍保持原权限边界。

按用户确认，SMTP 配置属于整个租户，各门店及相关产品线共用一份。首次保存后其他门店无需配置。配置页明确首次配置、已共用及旧配置待确认三种状态。保留租户管理员、tenant.admin.manage、真实门店归属、本人门店范围及至少一个顾客产品通过商业校验的要求；不开通其他产品、不扩展普通员工或顾客权限。

V128 新增租户配置表，只将旧门店中无冲突的有意义配置提升为租户共享配置。冲突旧配置保留回退并提示管理员确认，未配置租户保持关闭；关闭后的租户配置不会回退到旧的已启用配置。旧表、业务数据、账号和历史记录保留。开启前校验必要发信信息；空密码保留已有密码；响应无密码。保存与租户级审计同事务，审计不记录 SMTP 地址、用户名或密码。
