# 已开通产品目录与业务入口一致性修复（2026-10-26）

## 根因
产品线管理 list 固定列出 wallet/daily_ledger/wine_storage，没有过滤实际开通关系。租户侧栏和钱包收银台仅按 wine_storage.view 权限展示酒水寄存，权限不是商业开通。顾客钱包寄存摘要只要 /home 返回成功即显示，未区分从未开通且无历史。

## 合约与规则
- 管理目录 GET /api/v1/stores/{store}/tenant-admin/product-lines 只列当前租户/门店确有开通关系的管理产品，沿用 DTO、认证和权限。统一由 AppGate 判定，不针对特定租户/酒水产品写显示特例。
- 开通关系与业务可用性分开：从未授权（含未启用过的 disabled 行）不显示；租户曾启用、试用或到期的关系可保留管理。wallet/wine_storage 必须具有本门店商业订阅项；仅有其他门店订阅不能借用。其他历史 tenant-only 产品沿用既有规则。已开通过但门店关闭、到期/暂停仍显示管理卡片，以便关闭、恢复/说明续费。是否可开启仍由 evaluateStoreActivation 决定。
- 正常商户菜单（租户侧栏、钱包收银台）使用已有 /api/me/apps 的 entryVisible + 员工权限，加载/失败/切换门店时不展示旧入口。共享商品目录不跟随某一产品关闭。
- 顾客钱包：既没有新业务能力又没有物品、申请、领取意图、事件历史时隐藏寄存入口；仍有历史则保留只读/受控领取入口。既有服务端历史权限、领取校验及存酒快照完全保留。
- 产品线页没有已开通产品时显示空态；未包含酒水产品时不显示该产品专属说明。
无数据库迁移、无权限新增、无开通或订阅数据更改。没有提交部署授权，本轮仅本地实现。

## 测试清单
后端：未开通目录省略、过期/关闭可管理、从未启用与曾启用停用、当前门店订阅项缺失/隔壁门店、跨租户、原启用写入守卫。前端：无授权但有员工权限仍隐藏；已开通有权限显示；无权限隐藏；加载/失败不误显示；切店丢弃旧响应；顾客关闭空态隐藏、已有历史保留。

## 定位与实现审查
2026-10-26 对截图 sx 门店做只读查询：租户无 wine_storage entitlement，门店无该商业订阅和开关记录。原界面出现该业务来自固定目录与单纯权限判断，非实际开通。未改线上数据。
AppGate 新增开通关系查询 isStoreProductProvisioned，管理目录复用该查询；它不会授予业务权限，evaluate/evaluateStoreActivation 仍执行原授权。当前门店缺少订阅项不会借用其他门店。未改变 controller 的租户管理员/tenant.admin.manage/门店范围检查。列表数据结构与写接口不变。
侧栏与收银台采用既有 useStoreVisibleApps，加载期、API 失败和过期 store 响应均不显示该入口；支付/排队菜单也取消加载期间的默认显示。产品线页刷新成功会刷新侧栏查询；共享商品目录独立保留。
顾客历史摘要只调整入口判定，不碰存酒账户、业务记录、核销或授权流程。无数据库迁移，原有 12 项无关文件哈希一致。代码审查未发现未解决的必要项。
