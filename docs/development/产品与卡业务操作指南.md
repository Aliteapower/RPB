# 产品与卡业务操作指南

本指南对应 2026-10-25 本地开发版，尚未发布生产。

## 商户管理员

1. 从管理后台的“产品目录”进入，先创建分类，再录入产品编号、中英文名称、单位、价格和税务设置。中英文至少填写一种。
2. 将产品全局上架，并在需要使用的门店启用对应渠道。产品上架不代表所有门店、所有业务渠道自动开放。
3. 钱包“更多 → 卡与权益”，开启本店卡功能；进入“卡方案”新建集次卡、次数卡或周期卡，选择关联产品。
4. 配置总次数、每日上限及有效天数。周期卡当日未用额度作废；购买当天计第 1 个自然日。
5. 已发布方案不改写旧卡规则。需要新规则时创建新方案；停售只阻止新领卡/购卡，已有卡按原规则履约。

门店管理员可以调整本店价格、渠道和启停；共享产品资料、全局上下架及归档由租户管理员操作。

## 免费集次

1. 顾客在钱包首页打开“卡与权益 → 卡方案”，领取免费卡；商户也可以搜索顾客后选择方案领卡。
2. 员工搜索顾客或扫描其身份码，核对持卡、消费/签到来源，再点“增加一次”。相同来源不能重复集次。
3. 集满目标次数后自动产生独立奖励，顾客可随后兑换。集满不等于已兑换。

## 付费购卡

1. 顾客在卡方案中“申请购卡”，核对应收金额后向商户付款；申请本身不代表付款成功。
2. 商户在“购卡订单”找到原单，选择已配置的收款科目，填写账户、终端和实收凭证，核实实际到账后确认发卡。
3. 如已收款但报价过期或方案停售，不重复收钱；经理通过原单登记“异常实收”，再按原渠道退款并登记退款凭证。

## 消费核销

- 商户出码：员工选择卡或方案、产品对应数量，生成商户码；顾客扫码，选自己的卡并核对数量后确认。
- 顾客出码：顾客扫描本次商户单后，生成针对该单的授权码；员工扫描授权码完成扣次。普通身份码不能直接扣次数。
- 查看结果不确定时，先点“恢复待确认操作”或查原单，不另起一笔重扣。
- 总次数、每日额度、整体有效期同时生效。跨日后原授权不能改扣新一天，需重新确认。

## 记录与纠错

1. “卡业务记录”查集次、奖励、核销和冲正；较早记录使用“加载更早记录”。资金与积分记录仍在原业务中。
2. 核销错误由有权限的经理从原流水冲正。跨日冲正恢复原日记录，不补到今天；卡整体到期也不会因冲正延长。
3. 集次只能按未撤回流水倒序纠错；原轮次奖励已使用时不能直接撤回集次。
4. 未使用付费卡可按原单全额退款；已使用卡暂不支持退款。
5. “卡业务统计”分别查看售卡实收、退款和各产品单位的权益使用；未用日额度作废不是顾客消费。
