# 年度公共假期与月度店休本地验收（2026-10-29）

入口：员工考勤与薪资 → 管理 → 考勤设置 → 年度公共假期。管理员按年度维护；经理、员工在原有门店授权范围内读取。公共假期按租户共享，店休按门店隔离。没有生产部署、提交或推送；原工作区改动保留。

## 功能与规则

- 内置 MOM 2026、2027 官方日期模板，载入仅成为草稿，核对后保存。2026 有11个原假期和3个官方补假；2027 有11个原假期和1个官方补假。
- 可复制其他年份为草稿，重新生成ID、保留节日名、清空补休、标为待核实；农历及宗教节日须按当年日期修改。非模板年份不推算农历日期。
- 单独维护原假期、官方补假或约定补休日；“建议下个工作日”跳过周末和已设置的有效假期，须人工确认员工实际休息日。周六非工作日不能直接推导为全国周一公共假期。
- 每月多选确切店休日期，取消选择只停用旧标记，保留历史与原名称。店休不自动取消排班、创建请假或修改工资。
- 周表、月表、排班列表显示节日与补休原日期；员工考勤日历可见名称，无维护控件。英文名选填，缺省时回退中文节日名称。
- 工资公式、付款和历史核准快照未改；此轮建立可追溯特殊日期来源，后续假日工资仍须按适用规则设计，未一律套用2倍。

## 本地运行与迁移

按 `target/local-postgres-current.txt` 核对归属为D:\RPB、端口61644。V096仅应用到已有专用验收schema `workforce_browser_6b3d0ca974744b0c9b681036f8462dd6`；未修改public或其他项目数据库。原8095运行实例未动；新功能使用8096后端、5196本地代理。

迁移只添加年度表及假期表；没有自动种子写入或权限授权。年度写入在同一事务中锁定租户年度及该租户各门店日历，与原核准锁协调；月店休复用原CalendarService与审计。旧门店事件新增元数据为null且不序列化，保留旧源指纹；年度未改记录保持版本。相关日期改动会依既有来源复核机制要求重新核对，而不改旧核准快照。

需要回退本轮界面时恢复对应源文件/本地包即可，保留新表和配置，避免破坏性删除。任何生产升级仍需单独明确授权并按现有迁移流程执行。
