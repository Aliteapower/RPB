# 商户充值直接确认（2026-10-24，未发布）

## 实现与边界

- 商户选择一个活动档位及收款方式，点击“确定充值”；移除可见“获取报价”及报价有效期卡片。
- 复用现有 `WalletTopupOffers` 的 confirm-only 展示模式。后台仍先生成有效报价，成功后以 accountId、quoteId 创建充值单，不从客户端提交活动赠送金额。
- 无活动仍按普通金额充值；活动按单档选择。现金、PayNow、线下信用卡沿用当前可用渠道及配置。
- 显式使用当前活动所选渠道判断 PayNow 是否可用，修复与普通充值渠道变量混淆。
- 自动报价失败不创建单据；提交中禁用操作；报价期间切换账户、门店、档位或渠道不能继续创建旧单。
- 不确定响应的重试复用有效报价与现有命令幂等键。
- 生成单据不等于入账，仍进入实际收款核实页，保留现金收据选填与实际收款确认。
- 保留同一工作区此前“操作、交易记录和积分冲正分开”改动。本轮未提交、推送、部署。
