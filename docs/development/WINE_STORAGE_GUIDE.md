# 存酒卡简明操作指南

## 顾客

1. 从钱包打开“存酒卡”，选择实际寄存门店。
2. 点“申请寄存”，输入中英文酒名或编号，选择已有酒品；找不到时填写新酒名。填写瓶数、整瓶或已开瓶、本店购买或顾客自带，上传实物照片，可写备注。已开瓶每瓶新增一项、单独拍照。
3. 阅读门店保存规则后提交。此时只是“待商户确认”，现场交给商户核对后才算收存。尚未收存可撤销。
4. 在“寄存物品”勾选同一门店的物品和瓶数，点“申请领取所选物品”，出示领取授权码给商户。也可点“扫描领取码”，核对商户发起的物品及瓶数后点“确认授权”。授权不等于已领取。
5. 商户确认实际交付后才扣减瓶数。整瓶可部分领取，余下瓶数保留原到期时间；已开瓶整件领取。
6. 从“领取记录”的已交付明细点“再次寄存已领取物品”，重新填写数量、开瓶状态并拍新照片，重新走商户收存确认。原物仍在店内时不能用此操作延期。

到达页面显示的到期时刻即不能领取；提前申请、扫码或授权均不延长保存期。照片仅供实物核对，不估算瓶内毫升数。历史页面可查看原申请、商户修正原因及每次领取明细。

## 商户

1. 从钱包“更多”或租户管理导航打开“酒水寄存”。收存、交付、规则和纠错使用独立权限。
2. 首次使用先配置分类对应的保存规则：例如啤酒 3 个自然月、白酒 6 个自然月。新版本只影响后续收存。
3. 打开待确认申请，现场核对实物、酒品、数量、开瓶状态及来源。新酒名先查看同名候选，再关联已有产品或确认创建仅用于当前门店寄存的产品；不需要以 0 元填价格。
4. 每项补拍收存照片，选保存规则，填位置、标签及核对或修正原因，然后点“确认实际收存”。多瓶已开瓶需拆成独立瓶并分别拍照。不接收时填写原因拒绝。
5. 扫描顾客专用领取码，核对明细后确认实物交付；也可勾选同一顾客的物品，生成确认意图让顾客扫码授权，再完成交付。通用身份码不能领取。
6. 任一明细过期、数量不足或状态变化，整批不扣减；按返回的问题调整后重新申请。网络异常显示“恢复未确定的操作”时先恢复原操作，不另开重复单。
7. 后续照片在物品的“追加现场照片”中上传，确认追加后保存；纠错填写原因和说明，关联原物品，不改写原始数量和期限。过期记录仍保留，系统不自动登记实物处置。

租户管理员可在门店“产品线管理”关闭新业务，历史及期限内物品的受控领取保留。开关不代表取消商业订阅。新业务需平台启用、租户授权、门店商业授权及门店开关均有效。
