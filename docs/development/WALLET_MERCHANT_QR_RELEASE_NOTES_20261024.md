# Release Notes

## Version / Date
2026-10-24 开发完成，未提交／推送／部署。

## New
商户出码入口：消费付款码、积分兑换码。顾客既有扫一扫识别两种码，明确确认兑换后才扣积分，不抵现金。

## Changed
消费复用原账单确认流程及固定金额键盘；没有资金账户也可扫一扫兑换积分；下一位顾客清空手机号候选及未提交内容。原商户扫码收款和手机号充值／积分入口保留。

## Fixed
原消费出码入口缺失；新积分接口统一错误映射、幂等和过期检查；旧个人码测试同步120秒有效期。

## Validation
后端相关142项通过、前端回归127项及最后定向57项通过，前后端构建通过，隔离浏览器实际二维码图片完成消费付款和积分兑换／取消。详细证据见 WALLET_MERCHANT_QR_ACCEPTANCE_20261024.md。

## Migration
V065附加积分兑换意图表，保留既有资金／积分账本、历史和业务关联。仅隔离测试schema已应用。

## Permission
复用 wallet.charge.create、wallet.view、wallet.points.view/redeem，AppGate、租户／门店范围和本人归属，未新增权限或放宽整体路由。本地 allowlist 仅新增精确方法路径。

## Risk
未验证真机相机；消费码绑定已确认顾客，保持既有600秒有效期；积分码120秒。无预约、排队、清洁、日记账行为变更。

## Rollback Notes
回退应用并保留新增表及既有兑换entry，禁止删除历史／回写余额；撤销兑换依既有积分冲正。旧WB和个人码接口兼容。
