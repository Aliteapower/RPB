# 极窄屏横向滚动修复

2026-10-28，D:\RPB。用户授权验证通过后提交、推送及生产部署。

## 原因及修复
App.vue 的 body 固定 min-width:320px；约320px视口出现传统竖向滚动条后，实际可用宽度小于320px，导致整页横向滚动。
改为 min-width:min(320px,100%)，让最小宽度不超过实际包含块。没有隐藏 overflow、修改模块业务、表格滚动或标签栏滚动。
