# Release Notes

## Version / Date

2026-10-25-local：仅本地开发交付，未提交、推送或发布生产。

## New

独立酒水寄存模块及顾客存酒卡；申请/审核、实际收存、规则版本、专用双向领取码、同店批量原子交付、再次寄存、照片和审计流水。钱包仅提供入口、概要和专用码跳转。

## Changed

共享目录支持 NULL 价格的仅建档产品，存酒审核创建的产品仅投放当前门店 storage 渠道。目录维护可保留空价；销售报价需完成价格、税务和渠道配置。图片验证提取为共享基础能力，原钱包图片入口保留适配及原错误约定。

## Fixed

本次为新模块，不宣称修复其他钱包问题。

## Migration

V077 新增寄存表、复合归属约束、证据绑定及检索索引；允许目录价格/税务为空，不修改现有产品价格。原申请、收存快照、证据链接及流水保留，无删除或延期接口。

## Permission

`wine_storage.view`、`wine_storage.receive`、`wine_storage.deliver`、`wine_storage.rules.manage`、`wine_storage.correct`。按现有管理角色授予及新账号创建接入；普通员工不自动获得收存/交付权限。wine_storage 注册平台 AppGate；新业务要求当前门店商业授权，关闭后查询及有效旧业务履约仍校验身份与对应权限。

## Risk

未配置价格及商业授权前不能出售寄存产品或开展新寄存业务。不支持跨门店批量、过期领取、自动处置、延期、瓶内余量计算。本次验证证据及设备未验收项见 WINE_STORAGE_VERIFICATION.md。与订位、排队、入座及清台流程无业务耦合。

## Rollback Notes

如后续获准发布后需要停止新业务，先关闭 wine_storage 门店开关，保留新版本的历史及受控交付入口。不能通过回滚到不理解 NULL 价格的旧目录代码强行恢复服务。保留 V077 表及证据，不逆向删表、不将 NULL 改成 0；后续回退方案须先验证旧目录兼容性。本任务不执行上述生产操作。
