## 发现并修复

1. 多公司设置指引错误默认第一家公司：现在优先明确 query，其次当前门店所属且已授权的公司，最后才使用授权列表首项。工资首页同时优先当前门店公司；不扩大权限。
2. 同岗位月薪、时薪并存，新个人方案自动套用时薪：改为先明确选月薪 / 时薪 / 日薪，再预览应用；未选时禁用应用。保留既有方案编辑与估算入口。
3. 员工“我的工资单”藏在管理折叠区：首页直接显示本人入口，不再向普通员工显示“没有可管理的发薪公司”。不增加任何工资管理权限。
4. 确认后岗位信息丢失：新计算快照增加可选 positionName；冻结总表使用快照值。旧快照缺字段显示“岗位未留存”，不查询当前岗位伪造历史，不回填历史数据。

## 测试夹具修正及验收边界
