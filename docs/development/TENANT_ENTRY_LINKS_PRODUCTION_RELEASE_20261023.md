- New：租户后台“常用入口与二维码”，7 类入口，统一租户名称二维码，可复制、打开、下载 PNG。

- Risk：静态二维码改名后需重新下载；访问始终受现有产品、登录、权限和单店到期控制。超长名称中心可能省略，完整名称保留外侧。
