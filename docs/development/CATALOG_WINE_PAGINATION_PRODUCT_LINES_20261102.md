# 寄存选酒分页与分类产品线

日期：2026-11-02。范围：D:/RPB 本地实现。后续用户已授权补齐QA验收后提交、推送和发布，见 [浏览器验收与发布记录](CATALOG_WINE_BROWSER_RELEASE_20261102.md)。

## 行为

- 店员每款酒独立查询，每页6条，支持名称/编号及分类。分页在后端过滤后执行；查询、分类和清空回第一页，翻页使用已应用条件。保留直接点击选酒、清空、手动新增与独立多酒草稿。
- 分类增加适用产品线（可多选）：钱包积分 `wallet`、酒水寄存 `wine_storage`。业务内部卡权益/兑换/购物渠道映射钱包，寄存渠道映射酒水寄存，不混同产品线与渠道。
- 存酒首页、顾客选酒、店员选酒、新增酒品和规则分类仅接受寄存分类。寄存商品管理开放分类管理入口，默认新增范围为酒水寄存；通用目录仍显示全部分类供管理员维护。
- 保存商品/修改渠道由后端核实分类归属，跨店共享商品换分类也验证其他门店渠道。分类已有关联商品时不可移除在用产品线，锁分类行串行化与新增/调整商品的竞争。

## 数据库与兼容

V127 仅增加 catalog_categories.product_lines，按所有门店商品渠道、已有保存规则和申请行进行一次汇总回填；不按“酒水”“集卡”等名称猜测。无使用依据的旧分类保持待设置，可在通用分类管理勾选。历史寄存快照、库存、客户资料和原商品渠道不改写。

旧分类更新省略字段时保留归属；新增分类必须选择范围。新店员分页 API 复用顾客现有格式和权限边界，旧 products API 保留。新增分类范围不授予产品订阅、AppGate 或员工权限。

数据库审查：租户关联保持 tenant_id；原唯一/FK 不变，新增数组合法值约束；回填无删除。API 审查：见 [接口合同](../api/CATALOG_PRODUCT_LINES_20261102.md)，保持原401/403/404及400校验，分类在用409。不影响订位、排队、桌位和清洁流程。
