# 员工名单批量调整当天班次（本地实现）

日期：2026-10-29。范围：D:\RPB 员工考勤与薪资模块；未提交、未推送、未部署。

## 行为

- 从班次人数打开员工名单，选择调整日期，勾选员工、选择本页或选择当天全部，支持跨页保留选择，单次最多500名。
- 多选限定同门店、同一天、同一来源班次；同一天同一班次存在多个时段的员工继续使用单人时段选择入口。
- 弹窗选择目标班次，先预览可调整、无需调整及冲突项，再明确确认。仅调整可通过项，冲突和相同班次跳过。
- 原排班ID、员工和工作日期保持，更新班次快照及版本。有关联出勤、待审补卡、有效请假的记录不调整；目标时间与其他门店排班重叠也阻止。
- 成功后清空选择，刷新原名单、班次人数和排班表；原名单末页变空时回到有效页。原日期范围、筛选和表格滚动位置沿用既有刷新逻辑。
- 提交前重新检查预览指纹和版本；过期预览返回409。网络结果未确定时固定命令及请求重试，避免重复改动。

API契约：`docs/api/2026-10-29-workforce-bulk-adjust.md`。新增调整应用服务、预览服务与独立弹窗，复用原ScheduleService写入、审计和事务，未改动其他业务模块边界。

## 权限、数据与迁移

- 沿用AppGate、employeeManage与当前门店管理权限，没有新增角色或扩权。
- 源排班批量读取按tenant过滤，并在返回员工资料之前校验store；命令回执绑定tenant/store/actor及请求哈希。
- 复用V093命令回执，调整命令使用独立哈希前缀，不新增迁移。旧批量新增接口和回执兼容。
- 查询仅增加排班版本字段。原排班、打卡、工资及付款数据不迁移、不重算。
