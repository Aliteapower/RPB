## 环境与隔离

- 使用新建的 `[QA] 酒水寄存上线视觉验收 20261102` 独立租户、独立门店、两名合成顾客及合成酒品。所有存取操作均为合成记录，没有真实酒品交付。
- 店员端实际浏览器 CSS 视口覆盖桌面约 1214×755、手机约 391×844、极窄屏 321×844；顾客端覆盖桌面及 390×844。手机验收使用浏览器视口模拟，未使用实体手机或相机扫码。
- 浏览器实际登录、操作按钮并核对生产数据库中的 QA 记录；未向真实顾客发送消息或执行真实顾客写入。
- 验收期间生产其他租户的寄存表指纹发生变化。只能确认 QA 员工的跨租户寄存事件为 0，不能把全库指纹描述为未变化。

## 用例结果

| 用例 | 结果与证据 |
| --- | --- |
| 桌面保存不限时间规则 | 创建 v2，months=0；月份输入隐藏；新收存到期时间为空，页面显示不限时间 |
| 手机保存不限时间规则 | 创建 v3，months=0；单列设置表单可用 |
| 旧记录保留原规则 | 基线 5 瓶仍为 v1 三个月，原到期时间精确匹配；余额仍为 5 |
| 清除顾客 | 桌面和手机可恢复未选择顾客状态，顾客搜索清空、登记表退出；重新选顾客不带入旧选酒 |
| 搜索并直接选酒 | 桌面从搜索结果直接选中已有酒品；无需再到已有酒品下拉框重复选择 |
| 清空酒品 | 数量改为 4 后清空并重新选择，数量恢复为 1 |
| 未找到时新增 | 手机搜索无结果，切换新酒录入，名称预填；填写分类及数量后成功收存 |
| 桌面免扫码取酒 | 顾客未登录前，店员直接确认交付，4→2；无顾客授权事件 |
| 手机免扫码取酒 | 店员直接确认交付，3→2；无顾客扫码/授权；旧基线不受影响 |
| 顾客记录 | 合成顾客登录后看见店员登记的收存 3 瓶和交付 1 瓶记录 |
| 顾客出示码 | 可以生成取酒 QR，显示店员扫码直接核销；随后取消，记录显示已取消，余额仍为 2。未验实体扫码 |

备注：手机提交收存时，浏览器自动化鼠标点击曾报定位失败；先核对服务端没有写入，再用同一按钮的键盘 Enter 提交，最终恰好创建一条记录。这证明提交行为通过，但不能用该次操作证明实体手机触摸命中。
