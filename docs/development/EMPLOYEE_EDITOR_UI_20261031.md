# 员工编辑资料页面优化（2026-10-31，本地未发布）

## 业务体验

- 按用户要求保持单页，不使用分页或标签页。以维护员工资料为主任务，其他事项按需展开。
- 已有员工默认展开基本资料；任职与出勤资格显示岗位、任职状态和可用状态摘要，展开后编辑。
- 新增员工默认同时展开必填的任职、发薪公司和主店信息；保存后再办理薪资、登录管理和证件。
- 统一的“保存员工资料”按钮保存基本资料、任职信息和本次账号绑定。登录账号、薪资与证件区域说明各自的办理和保存方式。
- 登录管理、薪资资料和证件首次展开后才挂载，收起后保留组件和已输入内容；避免页面一进入就读取全部次要资料。
- 原生 details/summary 支持键盘展开；表单校验失败时同步展开包含无效字段的区域。桌面保存栏靠近操作位置，窄屏改为普通流式布局。
- 嵌入子区域时去掉重复标题与卡片边框；其他页面使用这些组件时仍保留原展示。
