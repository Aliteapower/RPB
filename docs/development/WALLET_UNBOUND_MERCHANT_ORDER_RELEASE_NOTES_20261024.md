# Release Notes

## Version / Date
2026-10-24，本地开发完成，未提交／推送／部署。

## New / Changed
商户直接输入消费金额或积分数量及兑换内容出码，无需查顾客。顾客扫一扫后一次明确确认，由本人会话决定付款人。首次成功确认才关联真实账单或积分兑换；两顾客并发或本人重试只成交一次，失败不占单。

## Preserved
个人钱包码、商户扫码、手机号充值积分、营销、本金赠送分摊、退款及积分不抵现金保持。旧已绑定WB/WR接口继续支持已打开页面；新入口使用WM码。无新权限、环境变量或依赖变更。

## Validation
后端138项、前端钱包回归127项及最后64项定向检查通过；类型检查、Vite构建、Maven打包通过。实际本地二维码PNG识别后完成消费10元和积分兑换5分，数据库各有一笔原业务；无手机号选择，顾客一次确认。

## Migration
V066新增wallet_merchant_orders意图表及约束／索引；原账本及历史不改。仅本线程本地隔离schema已应用。消费说明在统一交易查询中关联显示。

## Risk
真实手机相机、触控及生产规模负载未验证。新无绑定消费需钱包足额才能完成，原账单部分付款规则不改。新码有效120秒，过期重新办理。

## Rollback Notes
回退应用，保留V066附加表及真实资金／积分流水；不回写余额或删除历史，撤销使用原退款／积分冲正。验收证据见WALLET_UNBOUND_MERCHANT_ORDER_ACCEPTANCE_20261024.md。
