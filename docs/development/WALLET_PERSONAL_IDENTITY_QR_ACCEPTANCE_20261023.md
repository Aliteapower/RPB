# 顾客个人钱包码与先扫码办理验收

## 交付行为

- 顾客钱包首页与出码页统一显示“出示个人钱包码”；没有资金账户的顾客也可出码，用于积分操作。付款码保留独立用途。
- 商户“充值与积分”入口先扫描个人钱包码，核对顾客后再选择钱包充值或积分增减、兑换；不再在此入口手工查会员。
- 切换充值与积分保留已扫码顾客；重新扫码清除顾客和办理类型，自动打开扫描面板。其他页面手工选择的顾客不能跳过扫码。
- 新 WI 身份码有效期 60 秒，只识别身份，不授权扣款、不增加余额、不创建资金账户。旧 WP 个人充值码仍兼容；WC 付款码不能用于该身份入口。

## 模块与接口审查

身份签发/识别独立控制器、应用服务和仓储；前端独立个人码组件及扫码选客组件，充值与积分继续调用原有业务模块。身份识别返回顾客，不暴露资金账户或付款授权。充值和积分写操作保留各自权限与交易校验。

接口约定见 `docs/api/WALLET_PERSONAL_IDENTITY_QR_20261023.md`。签发使用顾客会话，识别使用员工会话及门店、租户、发行主体和商业授权校验，保留同源 CSRF 约束。V063 仅新增身份码表，存储哈希，复合外键约束租户边界，不重写资金或积分。
