# 公共日期输入统一发布（2026-11-03）

## 变更

预订、排队、收款、钱包、卡券、日账、人事及酒存输入统一使用 `src/components/common/DateInput.vue`。本次迁移 72 个页面/组件的 126 处原生输入，并将酒存报表包装器接入同一组件。日期、月份、本地日期时间分别显示固定格式，中文提示为“年-月-日”“年-月”“年-月-日 时:分”，英文提示为 YYYY-MM-DD、YYYY-MM、YYYY-MM-DD HH:mm，避免浏览器区域语言混杂。

保留日历选择和键盘输入；业务值仍为原有 ISO 日期、月份和带 T 的本地时间，不做时区换算。兼容 v-model、value/input/change、必填、只读、禁用、范围及时间步长。未完成草稿不作为日期传给接口；酒存查询显式拒绝非法草稿，重置同时清空草稿。普通文本、密码和年份数字输入不改。

新增 `docs/frontend/DATE_INPUT_STANDARD.md`，页面布局指南链接该规范；Vite 构建前运行 `scripts/check-date-inputs.mjs`，禁止页面新增裸 date/month/datetime-local 输入。模块仍拥有页面布局，公共组件拥有日期输入外观。

## 验证

公共日期及酒存回归 146/146 通过；类型检查通过。广泛回归使用 97 个非 Vite SSR 测试文件：修改前 1077 项（1051 通过、26 失败），迁移版 1084 项（1058 通过、26 失败）；失败名称集合完全一致，为原有固定日期排班/考勤失败，无新增失败。最终干净提交验证结果记录在发布证据中；不将基线失败报告成通过。

真实 IAB 在只读合成页面核验：三类输入、无效日期、时间步长阻止提交、有效输入、月份选择、只读/禁用、仅 value/change 回调和中英文提示。键盘输入回调实际更新父模型；自动 fill 后未触发 blur/change 的结果不作为该项证据。320px CSS 窄屏 client/scroll 均305，无横向溢出。此前酒存报表桌面及391/321px合成页面输入、查询、重置和等宽排列已验收。证据 `target/shared-date-preview/`、`target/storage-report-date-preview/`。实体手机、微信、每个私有业务页面及各浏览器原生弹出日历视觉未逐一验收。
