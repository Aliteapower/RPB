## Rollback

停机边界备份数据库、旧jar、完整前端及版本。持发布锁与预期旧SHA/制品哈希校验，核验上传哈希，只切换RPB；失败恢复旧jar和前端、旧版本元数据并等旧服务健康后再开放入口。V064为附加结构，保留，不自动回写/恢复数据库覆盖真实业务。旧版本无个人授权读取，恢复不启用新功能；若发布后已有顾客授权，不可将新个人版本误解释为管理员策略授权。

生产验收只进行匿名拒绝/同源保护、页面静态制品和数据只读核对，不替真实顾客充值、扣款或授权。实际发布SHA、备份、迁移及稳定性结果完成后追加。
