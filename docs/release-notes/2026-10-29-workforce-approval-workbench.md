# Release Notes

## Version / Date
2026-10-29 · 工时核准工作台 · 仅本地实现与验证，未提交、推送或部署。

## New
- 工时核准支持日期、岗位、姓名/编号筛选，正常、经理专审、异常、等待处理、来源变化及有效核准分类。
- 正常记录支持跨页全选、排除个别记录、预览总工时后统一确认；每100项分批提交，每条独立事务。业务冲突逐条反馈，未知响应保留同一批请求重试。
- 异常原地展开既有核准详情，保留异常决策、补卡/请假入口与历史；保存后刷新当前工作台。
- 显示门店每日进度，工资批次显示公司当月各店核准进度和有效工时。该检查不替代原工资确认前的配置、跨期来源等完整检查。

## Changed
- 经理仅能审核授权门店普通员工；关联账号具有管理角色或员工管理授权的员工记录统一由既有总部管理员审核。任何人不能核准本人。
- 以上权限同时约束原单条接口和新批量接口，历史核准不重写。

## Fixed
- 工作台和工时汇总不再静默截断为1000条；分块读取来源及最新核准，最多50000条，超出明确拒绝。

## Migration
无新增数据库迁移，无原始打卡或历史工资快照结构变化。

## Permission
复用现有AppGate、租户、门店、公司及工资权限；未新增人员授权。工资进度接口只返回汇总，不能绕过员工管理权限批量核准。Security仅放行精确路径与方法，并保留同源写保护和no-store。

## Risk
- 单次查询最多31天、50000条，已验证1002条真实数据库记录，未开展50000条生产规模压测。
- 核准仍须人工确认；待处理异常、缺卡、未结束班次不会自动核准。规则以后变动导致来源变化时仍需重新核准。
- 本轮不涉及预约、排队、到店、桌台或清洁工作流。工作区其他已有修改保留。
