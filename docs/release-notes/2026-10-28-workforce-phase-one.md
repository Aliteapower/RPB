# Release Notes

## Version / Date
2026-10-28，workforce 第一阶段本地开发完成，未部署、未提交或推送。

## New
独立员工考勤与薪资产品基础：公司发薪配置、员工档案、跨店工作范围、归属历史、仅打卡账号、已有账号关联、门店管理员与指定公司工资授权。紧凑中英文独立页面，适配窄屏。

## Changed
共享产品清单增加 workforce，接入员工首页和现有产品管理。旧产品业务规则、默认员工权限与数据不变。

## Fixed
开发审查期间修复旧账号停用/额外门店误阻断员工维护、账号选择控件意外卸载及切回原公司日期未恢复。

## Migration
V088新增5张workforce表及产品目录/新产品权限。不自动开通租户或门店。仅隔离本地schema已验证；原业务schema和生产未迁移。

## Permission
workforce.view用于产品入口；workforce.admin.manage仅总部管理员。门店管理显式委派，工资范围默认关闭。创建仅打卡账号无旧产品授权；绑定保留原账号权限。

## Validation
65项Java测试（含真实PG）、15项前端测试、14组实际API验收通过，前端构建和后端打包通过。实际浏览器新增员工成功，检查桌面及中英文390px布局。

## Risk
尚无打卡、请假、工资计算或CPF计算；没有真实手机/微信或生产验收。未执行全项目全部测试。新产品价格默认为disabled，正式开通需要配置。

## Rollback Notes
尚未部署无需生产回滚。未来应用回退保留新表及历史，停止新产品入口和写入，不删除员工历史；撤销产品授权不能连带撤销旧产品权限。
