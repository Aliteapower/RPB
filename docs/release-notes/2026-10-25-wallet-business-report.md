# 钱包收银台营业报表（已发布 008340b9）

新增独立营业报表，入口在收银台快捷区和更多页。支持日、月、年查询；月报按日、年报按月，提供期间合计、明细和 CSV。

支持按消费、充值、退款与冲正、积分大项筛选。所选期间没有实际交易的大项、小项和收款科目隐藏。显示与导出保持一致，金额与积分分开统计。

统计按门店时区和实际完成时间，待处理/取消业务不计入。现金流收款明细单独按实际收款时间列示，本金、赠送、权益不重复算作营业收入。保留原对账报表及每日营业记录产品。

权限沿用 wallet.reconcile.view，积分另需 wallet.points.view；未增加权限、迁移或依赖。只读访问不开户、不写交易，不影响预订、排队、散客、入座、清洁。
