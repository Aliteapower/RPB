# Release Notes

## Version / Date

2026-10-22，本地实现，未发布。

## New

新增 `daily_ledger` 每日营业记录产品线，独立Java/Vue模块。复用集团租户、经营主体、门店、账号、AppGate及门店订阅；默认 SGD 30/店/月、360/店/年。

迁入原站点累计现金/非现金、开支、底钱、抽大钞、餐段设置、Logo、字段录入与保存时间、草稿同步、离线恢复、清空撤销、员工提交锁定、管理员审计、历史筛选、收入/支出构成、每日/月度对比与CSV。历史配置及已提交快照独立冻结。

## Changed

每日营业记录UI按原站还原：侧栏、日报卡、餐段页签、现金明细、右侧汇总、已提交非现金回单、收支图表、十列历史账表及设置/提交弹窗。原站样式限定产品作用域并按职责拆分，门店切换与账号权限沿用RPB。桌面/手机浏览器核对、9项行为回归、类型检查与构建通过；本轮无新增迁移或API变化。

平台产品目录、租户后台导航、员工首页及新建管理员/员工的默认权限接入新产品。其他产品的业务状态机保持原逻辑。

## Fixed

AppGate对非本租户或不存在门店的拒绝审计改为tenant级审计，保留requestedStoreId，避免FK失败将403变成500。

账本页面语言切换改为正常文档流，避免在手机遮挡金额、桌面遮挡门店标识；限定账本页面生效。

## Migration

`V056__daily_ledger_product_line.sql` 新增5张作用域表、产品价及既有账号角色权限回填。生产应用此迁移前需随版本发布。

真实蜀香数据通过独立显式local导入工具迁移；4日期、7工作记录、6提交快照、89审计逐字段比对通过。source-export位于忽略目录，不在migration中；生产导入须使用经核对的新快照并另行授权发布。

用户已授权本轮生产发布和蜀香数据迁入。新增独立ledger-import模式，仅在显式导入参数下启用，导入成功关闭自身上下文；线上常规服务保持正常安全配置。发布前备份位置为 `/opt/rpb/backups/20261022-daily-ledger-before`，旧jar、前端和数据库dump均已保存；既有订位/排队/收款/订阅表留存发布前指纹，发布后比对。

## Permission

`daily_ledger.view`、`daily_ledger.write`、`daily_ledger.settings.manage`。员工仅前两项，租户/门店管理员拥有管理项；运行时同时要求平台产品启用、租户开通、门店开通及账号权限。

## Validation

41项Java测试、9项前端行为测试、Vue类型检查与生产构建通过；实际PostgreSQL约束、完整数据对比、真实登录、产品入口和越权403通过。用户完成本地登录后，管理员桌面/手机录入、清空刷新恢复、金额校验与重试、跨餐段抽款、最终提交、独立提交快照、历史/图表/CSV、设置及审计浏览器验收通过。测试记录集中在2099-12-30，原2026年10月报表保持一致；员工身份及真实付款未做浏览器验收。

## Risk

原单店员工密码算法不同；导入账号初始停用，由租户管理员重置后启用。沿用平台现有付款登记/订阅开通，不新增银行网关，不发生真实扣款。

## Rollback Notes

应用回退可先关闭daily_ledger产品及门店入口，回退本次应用版本；保留全部账本、提交快照与审计。不可为了代码回退删除已产生的营业数据。V056的价格/权限回填与新表需保留，不重跑或修改已执行的migration。原站点独立保留，可继续查询原记录。
