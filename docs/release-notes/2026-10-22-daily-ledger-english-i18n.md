# Daily Ledger 英文国际化（2026-10-22）

状态：D:\RPB 本地实现，未提交、未发布生产。保留前一轮门店品牌统一管理改动。

## 功能

- 接入 RPB 现有 zh-CN / en-SG 切换及浏览器语言偏好；模块独立维护双语目录，通过全局 vue-i18n 渲染。
- 覆盖营业记录、现金盘点、开支和抽款、汇总、提交确认、修改记录、记账设置、历史查询、图表、CSV、占位符和无障碍名称。
- 保存状态及已发生的错误在切换语言时更新；语言变化不触发保存、不重建录入组件。
- 内置早午晚餐标准名称可翻译显示；编辑设置仍显示原始配置。门店品牌、员工姓名、自定义收款/开支项目、历史备注、审计原始 payload 和输入备份不翻译、不改写。
- 日期标题使用界面语言；录入和保存时间继续使用门店时区及 12/24 小时配置，日期保留门店格式。金额、币种、冻结口径和计算规则保持原行为。
- CSV 在点击导出时读取当前语言，固定列及合计标题翻译；自定义渠道保留原名，金额及公式注入防护保留。
- 客户端按稳定错误码/HTTP 状态提供会话、权限、冲突和服务异常提示；已知领域校验详情有对应翻译，未知错误在英文模式使用通用重试提示。
- 修复手机端英文时段开关标签导致设置弹窗横向溢出。
