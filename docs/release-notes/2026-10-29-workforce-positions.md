# Release Notes

## Version / Date
workforce-positions-local / 2026-10-29；D:\RPB；仅本地。

## New
独立“管理”页面新增岗位管理入口，由管理员维护岗位目录，支持新增、编辑、启用、停用和未引用岗位软删除。岗位管理与管理员授权是并列功能。

## Changed
排班页操作区收紧：查询、新增排班和复制本周统一控件样式；周范围与时区、原复制限制和重试提示保留。25项前端测试、构建和实际页面验证通过；未新增批量业务或修改后端、权限和数据。

工资页紧凑整理：公司选择置于页头，计薪与付款、报表、对账及本人工资单按原权限使用统一入口样式；缴费规则改为可展开说明，内容保留。22项前端测试、构建及实际页面展开/收起验证通过，无业务或数据变更。

管理页进一步压紧为统一入口网格，薪资配置公司选择置于页头，工资模板和个人方案同其他入口样式；保留公司授权与参数。我的资料删除员工维护捷径，仅显示本人资料或未关联提示，员工维护继续从员工页进入。20项前端测试、构建及管理员实际页面验证通过，无后端、数据库或权限变更。

后续配置归并与身份展示：工资模板、个人薪资方案移入管理，保留原公司工资授权；仅有工资委派的人员也能进入薪资设置。工资页保留计薪批次、付款、报表、对账及本人工资单。管理员/经理进入排班、员工进入打卡；页头明确显示实际身份，兼有store_manager的账号显示经理。原个人资料和模板/排班路径保留。18项前端测试、构建及18项运行检查通过，无业务写入、后端或迁移变更。

班次模板移入管理，排班页保留排班操作；不改变原角色权限。

后续导航归并：发薪公司和考勤设置统一移入“管理”页面，顶部移除两个独立入口。门店经理在管理页保留原考勤设置权限；普通员工只读日历入口保留。11项前端测试、本地构建、12项只读运行检查及总部/经理实际页面验证通过。无新增迁移或权限调整。

员工岗位改为目录选择，采用稳定ID；原自由文本可按已维护名称兼容。停用岗位可保留原分配，不允许新增分配；被引用的岗位不能删除。

## Fixed
补齐岗位无统一维护及选择校验的问题，改名不会重写历史审计、冻结工资或付款。

## Migration
新增V092，迁入旧非空岗位并关联员工；保留job_title、员工版本与所有旧业务资料。真实Flyway升级与本地现有资料升级分别验证。

## Permission
沿用workforce AppGate及总部管理员维护权限；员工管理员只能读取选项并在原员工权限范围内选岗。无新授权、订阅或其他产品权限。

## Risk
本地构建、API、前端及真实PG验证见WORKFORCE_POSITIONS_20261029.md。未执行全项目回归、真实手机或生产验证；旧发布候选不覆盖本功能。原钱包改动保留，无预约/排队/Walk-in/座位/清洁业务修改。未提交、推送或部署。

## Rollback Notes
关闭workforce新写入或撤入口后，切回已验证兼容旧版本；保留V092表列、关联及工资付款历史，禁止降级删表。旧job_title可供旧版读取，但旧版不具备目录强制校验，不能在旧版继续任意写入后宣称目录一致。
