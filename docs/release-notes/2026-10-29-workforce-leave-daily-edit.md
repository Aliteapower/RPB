# 多天请假逐日调整（2026-10-29，本地）

- 逐日预览可编辑每个有效排班的开始、结束时间，按门店时区解析并重新校验班次范围和既有请假冲突。
- 日期勾选控制该日期全部班次是否纳入本次申请；取消勾选不会撤销已有申请或修改排班。再勾选保留已输入时段。取消、店休和无排班记录不开放编辑。
- 合计及待提交班次数自动重算；排除日期不计入总时长、不生成提交项。非法时段阻止提交，全部排除时不可提交。
- 每次逐日调整或勾选变化会使确认失效，必须重新预览后统一提交。响应未知时逐日控件同样锁定，重试仍使用原请求和每项UUID。
- 独立日调整优先于统一模板；统一时段只影响未单独调整的排班。改变范围或重新查询会重置本地逐日草稿，界面提供说明。
