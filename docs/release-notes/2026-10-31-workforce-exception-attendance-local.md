# Release Notes

## Version / Date

本地开发版 / 2026-10-31。D:/RPB；未提交、推送或生产发布。

## New

- 打卡核对、默认正常登记例外、免打卡按合同计发、自由免考勤四类独立策略，按日期采用并保存来源快照。
- 管理员异常月表与员工本人月历，正常留白，显示每天及每月加班、请假和待核对事项。
- 无排班区间例外与年度个人假期授额、结转、调整、占用及余额。
- 正常事项系统判定；合同加班按明确有效条款处理。

## Changed

工资直接采用新版带类型/版本的来源证据，无旧工资迁移/快照兼容。日历与工资共用日周加班计算；合同/自由不要求日常工时核准，不伪造实打小时。正式工资仍使用既有确认、来源变化和金额治理。

## Fixed

修复实打与额外工作双计、未来加班、跨夜归属、原/新请假冲突、跨月周阈值、信息性请假误阻断自由工资，以及自动任务审计source与真实数据库约束不匹配。原排班规则编辑器保留，新策略使用独立组件。

## Migration

本轮追加迁移现为V121–V124；已补入正式V114–V120原文，保留线上历史与校验和。提供42表工资专用数据精确清理工具，默认预览，拒绝未知依赖，不使用CASCADE；原始考勤、员工、合同、请假和共享数据保留。实际旧业务库清理尚未执行。新旧工资API/快照存在有意破坏性变更，不能把旧工资直接交给新版本读取。

## Permission

新增端点按现有workforce AppGate、门店及员工管理/本人权限校验；工资权限保持独立。普通考勤读取不包含工资金额、GPS、合同附件或敏感来源快照。自动判定使用系统身份并受商业授权检查。

## Risk

年度假期目前为显式人工授额/结转/调整，无按工龄自动计提。自动日判定覆盖当天及前7天，历史月份需显式刷新。未支持的月中混合政策明确阻断工资。前端274项回归有2项无关基线失败；移动端/完整语言视觉尚未验收。无生产、真实付款、银行或申报验收。Reservation/Queue/Walk-in/Seating/Cleaning流程未主动修改。

## Rollback Notes

本地保留原包及隔离验收schema。发布前应先核对实例、停旧工资写入、预览精确清单并按授权清理，再切换同一版本的前后端。旧工资一旦清理不能靠回滚代码恢复；需有明确备份才可恢复数据，不逆向删除Flyway或整个schema。新版已产生工资后的回退必须保留其审计与确认事实，不能简单再次清空。

详见[最终业务版](../superpowers/specs/2026-10-31-workforce-exception-attendance-design.md)和[验收记录](../development/2026-10-31-workforce-exception-attendance-validation.md)。
