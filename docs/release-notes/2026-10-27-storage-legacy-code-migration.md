2026-10-27。用户授权转换旧自动编号、保留自定义编号与历史记录，并提交部署。

V085仅转换同时满足code='WS-'+商品自身UUID且存在同租户storage.product.create审计的商品。类似WS前缀、自定义编号、缺少自动来源证明的商品不变。按租户分配未占用的1..99999数字，保留商品ID/分类/名称/渠道/状态及所有业务关联；仅更新当前商品code、version+1及updated_at。历史snapshot.code及原幂等响应不回写，历史酒品、数量、日期、取酒及再次寄存关联按ID保持原值。

新增catalog_legacy_storage_code_changes审计映射表，保存租户、商品ID、新旧编号、版本和原更新时间。事务内锁定商品表协调写入；号码不足或任一失败整批回滚。映射含租户与商品复合外键，不增加业务API或权限，不修改既有迁移。数据版本升至V085。
