# 卡业务四页统一布局（2026-10-27，已发布）

## 改动

- 卡方案采用紧凑列表，突出名称、类型、状态、价格和有效期/每日额度/总次数，创建表单统一控件间距。
- 购卡订单按行展示状态、金额、完整订单号和顾客标识；确认与退款表单行内展开，新增取消入口。
- 商户卡业务记录按行展示数量、时间、前后额度、来源、原单与原因；冲正入口保持原权限及已冲正限制。顾客历史使用独立展示分支，并随本轮顾客 UI 一并优化。
- 统计页提供日期标签、金额摘要、业务明细及作废额度表；区分集次奖励与积分兑换，保留原始单位和零值。
- 桌面与手机、中英文共用商户页样式；窄屏表格在容器内滚动，不压缩金额或隐藏字段。商户面板样式独立于共享 commerce 和顾客卡页。
