# 员工考勤与薪资第四阶段（本地开发记录）

日期2026-10-28；未提交、未推送、未部署。

## 行为
公司自然月工资批次已可使用：模板复制到个人方案→读取有效核准工时→计算→确认冻结→发布本人工资单→登记付款/冲销。月/日/时薪、同公司跨店日周加班、2026普通工资CPF/SDL、明细工资单及打印界面独立模块化实现，12个紧凑双语页面。

工资权限必须明确公司委派，员工管理权限不授薪资。本人不能确认自己的批次或登记自己的付款；员工只看已发布本人单，不返回生日/PR或管理备注。来源变化不能偷偷改冻结金额，付款和一次反向记录均保留。

## 验证
248项后端相关执行、63项前端测试、83组真实API、前后端构建及实际浏览器链路通过。独立审查必要问题已真实复现并修复，确认/考勤竞争和并发防超付均有真实PostgreSQL验证。
