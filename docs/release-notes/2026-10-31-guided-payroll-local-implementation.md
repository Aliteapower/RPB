- 个人补发带入员工、原月份及原单，使用现有审批和差额结算。月底补充统计区分原正式工资和已正式补发，已确认未付也纳入防重统计；缺完整原单时合计为空，补发小计仍显示。

## 在职分段结薪补充实施（2026-10-31）

### 业务行为

独立入口支持离职或在职员工，从本月起按连续已结束营业日期分段：建立草稿 → 测算 → 核对累计/此前正式/本次差额 → 确认冻结 → 独立发布 → 按实际付款登记或冲正。草稿可修改累计单位、说明和核对状态后重算；正式单不释放覆盖范围。月底剩余期间继续走独立单，普通整月批次只处理未进入独立结薪的员工。

累计计算复用既有工时、周加班、薪资、CPF、CDAC与SDL内核，减去所有已正式结算金额，包含已确认未付款。固定/人工月薪须核对全月工作日分母及截至本次累计应付日；不按日历比例猜算。月内分母、真实CPF档案及政策不能通过后续段偷偷重新核算已结前缀。

已结前缀来源后来更正时，原金额和引用保持冻结，总表显示独立补发/纠错提示；后续段仅增加未结期间，不把更正自动当作新增工时。OW补发进入后续累计目标和此前已结额，基础年度事实保留原薪，补发沿原独立链追加，避免年度和现金重复归集。

统一月底对账显示普通正式工资、分段正式结薪、正式补发，人员去重；公司SDL先按个人完整精度合计再按政策舍入，减已正式责任。工资所属期与付款日期仍区分，发布不代表付款或到账。员工只能看到本人已发布覆盖期间、本单核准工时、计薪标准/应付日、三组金额和公开付款记录。
