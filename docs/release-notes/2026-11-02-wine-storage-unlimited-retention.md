## 功能

保存规则可选择“按月保存”或“不限时间”。切回按月保留已输入月数。保存仍追加新版本，仅影响之后的新收存；历史快照及到期日不变。不限时间酒品可按原流程取酒，仍校验瓶数、归属、授权、幂等及并发扣减。领取授权码继续按原时间失效。

顾客、商户、库存筛选及 Excel 导出支持“不限时间 / No time limit”，不会显示伪造的远期日期。

## 接口和迁移

原 POST /rules 接受明确的 months=0 表示不限时间；1–120 保留自然月语义，缺失/null/非整数/越界拒绝。物品及库存行 expiresAt 可为 null；授权码 expiresAt 仍必有值。V126 放宽月份约束并允许物品 expires_at 为空，不更新历史数据。权限、租户及门店范围不变，无新增 App Gate 权限。
