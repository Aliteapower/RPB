# Release Notes

## Version / Date

2026-10-22，产品线接入修复；基础提交 `311cce291d5efd8f89d988ec87edb63ce2084dfc`。用户已追加授权提交部署，部署结果另行记录。

## New

- 代码随包发布的 `product-line-entries.json` 同时供后端和 Vue 使用，集中声明已实现入口、标签和入口权限。新增产品需要显式注册，不能通过数据库 JSON 自行授予入口权限。
- App Gate 增加只读门店订阅有效期投影。已按门店计费的产品，到期门店接口返回 403 `STORE_APP_EXPIRED`，可见产品列表隐藏入口；其他有效门店继续使用。续费后无需手工重置门店开关即可按已有同步流程恢复。

## Changed

- 默认入口选项包括员工首页、PayNow、每日营业记录及空入口。产品创建、显式编辑入口和只修改名称时使用同一后端白名单。
- 营业记录仅从统一资料服务读取门店名称及当前租户 Logo。产品私有英文名及旧 Logo 不再作为当前展示回退；旧 JSON 原样保留，显式品牌迁移仍可使用。

## Fixed

- 修复独立产品路由被后台白名单误拒。
- 移除 App Gate 中按产品编写的入口权限分支，入口权限改从受控共享定义读取。
- 修复兄弟门店续费导致聚合授权延长后，已到期门店仍能使用产品的问题。
- 修复清除公共 Logo 后产品复活旧 Logo 的问题；增加 actor 与请求租户一致性校验。

## Migration

无需新增或修改 Flyway 迁移，无业务数据回填或删除。PostgreSQL 验证使用 `D:\RPB\target\local-postgres-current.txt` 的 61644 端口、`postgres` 数据库，在测试新建的隔离 schema 内运行迁移与测试，完成后删除测试自己创建的 schema。未启动/替换既有后端及前端服务。

## Permission

无新角色、动作权限或自动租户开通。现有产品的入口权限集合保持不变，注册表测试验证其与既有权限常量一致。接口权限、门店访问权、平台/租户授权和门店开关继续独立生效；前端增加单店到期中英文提示。

## Risk

- 历史纯租户授权、无门店明细订阅及 `legacy_grant` 保留既有授权方式；本次不自动转换历史商业模型。
- 本次只强制门店结束时间，不新增未来生效时间规则；现有提前续费会把期间开始时间写为下一周期起点，直接据此限制会误停当前使用。
- 仅存在产品私有 Logo、尚未接管到公共资料的商户，会显示默认图标；应经既有显式迁移或公共资料维护完成接管。原数据没有丢失。无公共英文名称时使用产品默认副标题。
- 全局平台/租户停用仍优先于门店状态；新错误码保持既有 `success/error` 响应结构。

## Rollback Notes

生产未发布，无生产回滚动作。本地撤回时只撤回本次文件改动；既有需求文档与 `rpb信息.txt` 不属于清理对象。未来回退版本时必须保持前后端注册表版本一致；旧代码会恢复旧的单店到期授权缺口。无需删除订阅、业务表或旧品牌数据。
