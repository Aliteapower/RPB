# 商品卡片快捷取酒码（2026-10-26）

## 行为

顾客“我要取酒”的商品卡片右上角新增领取瓶数和“出码取酒”。默认1瓶，可领取多瓶；只允许正整数且不超过本商品剩余瓶数，开瓶酒沿用一次1瓶规则。点击后原位展示二维码、本次领取数量、有效期及“商户扫码即核销”，支持取消。原多商品选择、核对清单和取酒记录流程保留。

二维码复用顾客 `/intents` 授权和商户 `/scan-deliver`，不自动授权全部余量。展示期间轮询及页面恢复可见时刷新服务端状态；核销、取消后隐藏二维码，商品余量随首页刷新。仅保留当前会话的明文码，刷新页面后不会从历史记录还原令牌。未确定的请求继续使用原幂等恢复入口；出码中禁止重复点击。

## 权限、数据与回退

无新增 API、迁移、依赖或权限。沿用当前顾客会话、租户/门店归属和服务端库存/期限/授权校验；无预约、排队、入座流程变化。未提交、推送或生产部署。回退本轮存酒前端文件即可恢复原入口，保留业务数据和已生成领取意图。
