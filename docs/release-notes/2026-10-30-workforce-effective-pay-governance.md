# Release Notes

## Version / Date

本地阶段3有效薪酬版本治理，2026-10-30，D:/RPB。尚未提交、推送或生产发布。

## New

- 工资模板、个人方案、月输入的仓储级完整证明校验；PayrollLine携带有效版本来源，历史沿用固定源版本。
- 安装时合法历史资料登记legacy证据，未来已批准月份在旧批次作废重建后仍有效。

## Changed

- 旧金额写接口遇到需审批变动返回409 `WORKFORCE_PAYROLL_APPROVAL_REQUIRED`，转统一申请。首次发布模板原样采用及已有经济内容不变仍可直接维护。
- CDAC批量改为逐人提交统一申请，返回submitted/failed/stale及requestId；提交不代表生效，理由与法律凭证分开。
- 新居民必须有明确CDAC标准适用性资料；不按国籍、姓名推断族群。缺声明的影响预估返回未知金额及问题码，完整明确的待批选择仍可预估。

## Fixed

- 原批次输入不能覆盖稳定批准月版本；生成单位原样回传仅维护备注/工时核准，不保存隐藏未审数值。
- 旧JSON缺可空字段兼容完整类型比较，旧批准不能回滚新方案；单个或相同作废基线不丢失，真实不同基线阻断。
- CDAC逐项提交前重检完整预览内容，同ID新版本返回stale；已有其他开放提案不被覆盖或自动提交。

## Migration

V110新增不可变有效证据、legacy月份及CDAC命令/逐项回执。登记存量不重写原profile、工资、发布与付款JSON，不伪造审批。已在自建随机测试schema运行真实有数据迁移，未应用到生产业务schema。

## Permission

沿用租户/公司/门店范围、App Gate、工资权限和同源写保护，没有新增员工管理可改薪权限。Reservation、Queue、Walk-in、Seating、Cleaning流程未改变。

## Risk

新写接口与CDAC响应契约需对应前端同步。增量引擎版本升级使未确认缓存重新计算；历史冻结工资及付款不重写。最终42项受影响回归全部通过，原177项失败及修复证据完整保留于阶段报告；性能基准、真实手机、银行、CPF平台及生产验收未执行。奖金/AW/补缴后续阶段仍待实现。

## Rollback Notes

V110为追加迁移，保留证据和稳定批准月记录，不通过删除证据回退。旧后端会绕过新守卫且不认识稳定月来源，不能单独回滚旧二进制后继续工资写入；如正式发布需回退，先暂停工资配置/批量提交与确认写操作，保留数据库，修复或恢复兼容本契约的后端后再开放。本阶段未执行任何回退或清理。
