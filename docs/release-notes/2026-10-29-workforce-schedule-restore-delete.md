# Release Notes

## Version / Date

员工考勤与薪资排班恢复/删除，2026-10-29；仅本地，未部署。

## New / Changed

取消记录弹窗新增恢复排班；无关联打卡的有效或取消排班可删除。恢复保留原ID与快照，提交检查冲突。删除从表格隐藏，数据库行和审计保留。周表/月表/列表优先显示有效排班，无有效项仅显示最近取消项，删除后不回显旧取消卡片。复制到下周不包含取消或删除记录。

## Permission / Data

原AppGate、租户、门店及管理权限不变。已有出勤、待审补卡、有效请假关联禁止调整/恢复/删除；原打卡及工资数据保留。重试使用原版本，防止重复审计。

## Migration

V094新增nullable deleted_at和取消状态约束；只在本地验证库执行，原20条排班字段及业务/打卡摘要不变。无生产迁移。

## Validation

55项前端测试与构建通过；81项后端场景及5项实际API检查通过；页面新增/取消/恢复/删除流程实测通过。证据见对应开发验证文档。

## Risk / Rollback

恢复限今天至未来90天且原班次启用；删除项不提供恢复。回退代码保留V094列和审计/业务行，不物理清理；旧版本可能重新显示软删除项。无提交、推送或部署。预约/排队/到店/落座/清洁/钱包业务未改。
