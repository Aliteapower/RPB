# 卡业务报表发布说明（2026-11-03）

## 新增 / 调整

商户和员工端将记录、统计合并为卡业务报表。支持日期、顾客、卡方案、业务类型筛选，服务端分页，全量查询汇总及按顾客/方案、单位分组。额度过期独立呈现，不计入消费。办理时间与业务日期分开；审计编号收进详情。补齐集次撤销及净发生量，保留原冲正命令和历史数据。

## 验证 / 权限 / 数据

44项卡业务前端、421项相邻前端回归通过；45项后端回归及最终10项报表专项通过；类型检查和构建通过。桌面、390px中文、320px英文合成接口浏览器验收通过。生产发布使用干净提交源码重建并核对制品。

复用现有卡查看权限、App Gate、租户/门店隔离及历史只读规则。没有数据库迁移、依赖、配置或权限新增。预订、排队、入座、清洁的业务实现不变。实体手机和生产私有账号交互、大规模压力未验收。

## 发布检查 / 回退

前后端须配对发布，新前端依赖新增reports接口。发布锁内检查旧版本、制品哈希、环境、数据库版本及其他服务身份；保留旧JAR、前端入口、版本标记和历史静态资源。服务器磁盘紧张，不清理既有数据；采用增量制品上传和旧JAR硬链接，数据库备份流式保存本地并核对完整性，部署前按实际新增字节预算校验余量。

失败时成对恢复本次备份中的旧JAR、index.html、frontend-version.json和版本标记，再启动原后端；不恢复数据库覆盖新业务。没有schema回退步骤。生产验收只调用必要查询和权限保护接口，不发卡、不消费、不冲正、不改真实订阅。
