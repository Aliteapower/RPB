# 存酒快捷存取：无需顾客扫码授权

日期：2026-11-02；D:/RPB本地实现，未提交、未发布生产。

## 功能

默认“顾客核销”展示改为“快捷存取”：顾客保留本人记录、存酒申请、取酒码；店员既可扫描顾客取酒码核销，也可识别顾客、选择酒品和瓶数、确认实物交付后直接扣减，不再生成要求顾客扫码授权的确认码。普通顾客码继续只识别身份，识别后可快速转入存酒/取酒，不凭身份码直接扣酒。

旧未完成商户取酒单可由有权限店员直接确认交付，不再等待顾客扫码；保留原5分钟操作超时及酒品期限。顾客端移除“扫描商户确认码”的新操作入口。直接登记模式仍以门店办理、顾客查询记录为主。

## 审计和兼容

直接办理记录staff.delivery_registered，注明实际模式和办理人；未发生顾客authorize则不新增authorized事件。既有已完成记录不回写。沿用customer_verification / staff_registration枚举和已有API，无新增迁移、权限或App Gate规则；酒品有效期、数量、顾客归属、租户/门店、整批原子性、幂等和并发扣减仍校验。前两轮“不限时间”和登记选酒优化保留。
