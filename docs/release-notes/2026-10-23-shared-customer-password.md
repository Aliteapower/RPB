# Release Notes

## Version / Date
2026-10-23，共享顾客与手机号密码登录；用户已授权提交部署，实际发布结果见 [发布记录](../development/SHARED_CUSTOMER_PASSWORD_PRODUCTION_RELEASE_20261023.md)。

## New
- 钱包、公开预约共用手机号密码登录和自助改密组件。初始密码为已登记手机号后六位，新密码至少八字符。
- 密码采用 BCrypt；初始化和改密记录不含敏感值的审计。改密撤销该顾客全部旧会话并替换当前会话；失败登录按手机号和 IP 持久化限流。

## Changed
- 顾客模块统一所有产品线的租户共享目录，钱包员工可直接选择后台已有顾客，无需顾客先注册／登录。
- 后台正式顾客建档、修改须填手机号，同租户同号码唯一；姓名和邮箱不作为自动合并依据。
- 预约预填登录档案手机号，通过预约不能改掉已有手机号。旧邮箱／OAuth API 保留兼容，新界面使用手机号密码。

## Fixed
- 钱包顾客列表与租户管理列表采用同一数据源，去除登录账号过滤。
- 已设置密码不会因改号恢复默认密码；me 支持当前门店租户过滤，防止跨租户入口显示其他租户会话资料。

## Migration
V058：认证账号邮箱改为可空，新增租户顾客密码凭据和限流表。不重写顾客、余额、流水或账单；历史无手机号档案保留，新开户先补号。无短信供应商或新依赖。

## Permission
沿用租户管理角色、钱包动作权限、门店访问及 App Gate。改密必须具备有效顾客会话并验证旧密码；登录不能自动注册、不接受客户端选择租户。

## Risk
初始密码按业务要求可由手机号推知，界面提示顾客自行改密；不强制改密。历史无号顾客需要管理员核实补号；冲突档案不自动合并。尚未生产发布或执行生产数据补录。

## Rollback Notes
回退本轮前后端代码，保留 V058、密码凭据及审计，禁止删除或重新生成顾客／钱包记录。旧邮箱登录保留，但新手机号账户邮箱可空，回退后旧界面无法使用手机号密码入口。

验证和审查证据见 [验收记录](../development/SHARED_CUSTOMER_PASSWORD_ACCEPTANCE_20261023.md)。
