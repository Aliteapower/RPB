# Release Notes

## Version / Date

员工考勤与薪资：整周批量复制，本地实现，2026-10-29；未部署。

## New

整周复制冲突预览：展示员工、源日期、目标日期、班次、时间、状态和原因；默认不覆盖已有排班，跳过已有和冲突，仅提交可新增项。支持最多5000条、1000名员工；详情50条分页，超限明确提示。

## Changed

从目标周一当天复制到周日，按原星期对应；成功刷新目标周，下一次目标自动加7天。结果未知使用原命令重试，避免重复。单条、批量新建、周表/月表/列表保留。

## Fixed

旧复制遇到目标日已有排班会整体失败；新入口先预览并跳过已有项。移除新页面的100条限制。

## Migration

无新增迁移；复用V093批量回执。保留旧复制API，旧调用语义不变。

## Permission

沿用租户、门店、AppGate、workforce.view和原管理门店范围；管理员和有原管理权限的经理可用，普通员工拒绝。无新增权限或扩大授权。

## Risk

有界事务在提交时冻结同店排班写入，最大5000条、1000名员工；本地容量测试通过，尚无生产负载延迟验证。使用当前启用班次模板；历史快照保持原样。其他产品线无业务变更。

## Validation

51项前端测试、类型检查/构建、后端复制/接口/安全链、原批量排班与出勤回归，以及实际页面复制/跳过/目标顺延验证通过。原13条排班及员工/工资/付款/账号摘要未变；本轮两个新增测试排班已取消并保留历史。详见开发验证文档。
