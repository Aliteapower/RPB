# Release Notes

## Version / Date

2026-10-28；D:/RPB 本地未发布。

## New

租户管理员可在员工编辑页按门店配置预约排队、PayNow、钱包、积分营销、卡券、存酒及每日账本的查看、操作和可委派管理权限。支持保存、撤销、必要查看依赖、版本冲突和授权审计。

## Changed

已有员工未配置的门店沿用旧权限；保存后使用明确集合，全部取消可撤销所列模块权限。权限更改下一次后端请求生效，前端路由切换刷新当前门店权限。

## Fixed

卡券管理补齐只读选品依赖；存酒只读员工可查顾客历史；PayNow开关与实际建立/手动确认权限一致。员工只读商品权限不显示管理员专属商品管理链接。

员工账号创建/编辑接口封住同租户内的门店越权：管理员只能变更自身有权门店，其他门店既有归属及原默认门店保持；前端同步禁用无权门店修改。

## Migration

新增 V087 auth_staff_store_permissions；保留原账号权限与业务数据。迁移需要先于新后端上线。

## Permission

复用现有业务permission code，无角色晋升。平台权限、租户管理员身份及硬角色限制的设置不对普通员工开放。商业开通、停用、到期和门店访问继续受原AppGate约束。

## Risk

前后端应配套发布。旧版本忽略新配置；目录外人工特殊权限继续保留。当前页按钮可能在下次路由刷新前显示旧状态，但接口按新权限拒绝。

本地验证：103项后端定向回归（含8项真实PostgreSQL测试）、31项前端行为测试、构建及diff检查通过。未进行线上或真实移动浏览器验收。

## Rollback Notes

不能直接回滚旧后端并假定撤权仍有效：旧版本会重新使用账号基线，可能恢复已撤销能力。如确需回滚，应先暂停受显式配置影响的员工账号或阻断相关业务入口，核对原账号权限后再恢复。保留新权限表和审计记录，不盲目删除表或还原账号授权；本轮没有执行回滚或部署。
