# 常用入口系统化修复（2026-11-02）

## 修复

- 新生成的常用链接、名称二维码与预约分享地址统一使用配置的 HTTPS 主域。新增租户不需要先为新子域签发证书才能分发这些入口。
- 公开路径携带门店 ID；员工与管理员入口保留 tenantCode、登录类别及本门店内部 redirect。原子域登录与后端范围校验保持不变，共用主域时可能需要登录目标租户。
- 产品的顾客、员工、管理分享入口集中声明在 `product-line-entries.json.distributionEntries`。未声明额外入口的产品默认复用注册的员工路由；新增顾客入口必须明确注册，路由行为测试会检查所有当前产品的目标页面、公开边界及门店参数。
- 常用入口接入既有30秒可见页面刷新，开通、到期与恢复不必重新加载页面；失败清除可分发内容、切店隔离迟到响应、同店请求不重叠、卸载清理监听。
- 统一主域后的跨租户顾客会话：钱包或存酒首页返回403/404时，清除旧数据并通过已有 `customer-auth/me?storeId=` 只读确认目标门店会话；明确401才显示目标门店登录。已有有效会话的产品拒绝与查询失败保持原错误，不自动退出、不复用另一租户身份、不重放命令。检查超时或失败不能推断身份；迟到响应仍受门店与请求序号保护。

## 数据与兼容

不新增迁移、API、订阅写入或权限。Java 共享产品目录记录仅增加可选分享元数据的解析能力，不改变 AppGate 产品集合、业务路由或授权条件。无真实资金、工资、存酒或顾客资料改写。

新二维码改用主域；已下载或印刷的旧二维码内容不会自动变化，原子域证书仍须单独维护。

- 13项关联后端测试通过：共享目录解析、入口服务、匿名与越权拒绝、只读接口、真实 PostgreSQL 租户/门店隔离及主域/子域解析。数据库使用 `D:/RPB/target/local-postgres-current.txt` 指向的61644实例与随机测试 schema；测试 schema 由自有测试清理。
- 类型检查和 Vite 构建通过。最终发布使用提交的干净源码归档重新构建，并单独记录制品及生产核验。
