# 统一扫码设备设置与扫码枪兼容

版本：2026-11-04，前端 `85d86bd8` 已部署，后端保持 `3abca5b1`。详见[生产发布记录](../development/SCAN_DEVICE_PRODUCTION_RELEASE_20261104.md)。

本期浏览器目标：Windows 桌面版 Chrome 和 Edge 当前稳定版。没有实体扫码枪时先进行键盘模拟的软件流程验证；两个浏览器的实际验收和 HID 实机验收分别记录，当前均未宣称通过。

## 新增

- 本机、当前租户和门店可选择相机或 HID 扫码枪，员工顾客码和商品条码入口共用设置。
- 扫码枪支持顾客个人码、卡核销码、取酒码及瓶身商品条码。统一核销成功后自动接收下一张，明确已付款后清空顾客并恢复接收，保留账单入口。
- 商户直接存酒可连续扫码选品和增加待确认瓶数；商品维护可扫码填条码。

## 保留的业务规则

金额、顾客确认、权限、租户/门店作用域、幂等及未决结果恢复继续使用原流程。商品扫码只改草稿，不自动收存或新增商品。顾客公共页面的扫码方式保持原有相机行为。

## 验证与限制

关联 169 项行为测试通过，独立审查通过。完整前端回归中的 27 项失败在去除本次变更的对照副本中同样复现。构建及具体证据见[验证记录](../development/SCAN_DEVICE_COMPATIBILITY_20261104.md)。浏览器被 Work 设置禁用，登录后视觉和实体扫码枪未验收。

## 迁移、权限与回退

无新增 API、权限、后端、数据库迁移或依赖。可将本机设置改回相机；代码回退只涉及本次前端改动，不回退数据库。原有订位、排队、散客、座位与清洁业务不变。
