# Release Notes

## Version / Date

员工考勤与薪资：班次人数及同店同步，2026-10-29，仅本地未部署。

## New

各班次区间人数/人次汇总，周表/月表每日班次人数。覆盖当前门店及已应用筛选的全部员工页，取消和删除不计。

## Changed

管理员与已授权经理共用同店日历；页面可见时每15秒、切回页面时检查更新。编辑弹窗期间暂停，失败保留上次内容并提示；权限收回清空旧表。日期、筛选、页码和表格滚动保留。

## Permissions / Migration

原租户/门店、AppGate和管理权限不变；不允许跨店使用预览或回执。无新端点、权限、迁移。管理员可显式切换已授权门店；经理仅限已有管理授权范围。

## Validation

63项前端、44项后端相关回归及逻辑删除统计定向复验通过，类型检查/构建通过。实际管理员→经理、经理→管理员复制结果一致；经理页自动出现新增排班和人数。原22条排班及业务/打卡摘要未变，本轮三个测试排班已逻辑删除。

## Risk / Rollback

15秒轮询非实时推送，编辑/后台/网络故障会延迟显示更新。恢复配套上一前后端构建即可停止统计和自动同步；保留原业务行、审计及回执。未提交、推送或部署。
