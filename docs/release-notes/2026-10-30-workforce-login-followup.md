# 员工编号登录与停用账号改密

2026-10-30，承接本批已授权发布。

- 新增打卡账号直接使用员工编号登录，不再另填用户名。
- 有权管理员可给停用员工重设密码，保持停用状态，不自动恢复登录。
- 已有专用打卡账号可显式改为员工编号，原密码不变，原会话撤销；多产品共用账号不在此改名。
- 明确区分账号停用与管理权限不足。

无数据库迁移或新增产品权限。员工编号冲突拒绝覆盖；本人、总部账号及跨租户/门店管理限制保持。回退应用不回写已修改用户名、密码或会话；需告知员工采用当前实际登录名。
