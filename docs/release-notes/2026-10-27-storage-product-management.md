# 存酒设置内商品维护

存酒设置新增“酒品名称 / 商品管理”入口，管理员可在原页面内查询、编辑及启停本店勾选“寄存酒”的商品，复用现有商品编辑器，无需进入产品目录。停用及下架商品仍可查询恢复；搜索和分页在数据库筛选后执行，避免受通用目录500项限制。

沿用catalog.view、catalog.manage、catalog.publish及租户/门店权限。商品名称与全局状态仍为租户共享，本店停用影响该商品本店所有渠道；仅停止寄存酒用途可编辑取消“寄存酒”勾选。无数据库迁移，历史寄存快照保持原值。

验证：8项后端测试、71项前端回归、生产构建及diff检查通过；319px本地浏览器夹具检查列表和编辑器无横向溢出。已有紧凑存酒子入口及其他工作区改动保留。本轮尚未提交部署，未进行生产业务写入验收。

后续授权发布：2026-10-27与紧凑存酒子入口共同以8ca25c8b上线，前后端版本一致；线上分页查询、权限拒绝、清单及Excel导出验证通过。回退恢复本次发布备份的JAR、index及版本标记，保留业务数据。完整证据见docs/development/STORAGE_PRODUCT_MANAGEMENT_RELEASE_20261027.md。
