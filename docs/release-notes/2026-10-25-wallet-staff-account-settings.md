# 钱包收银台账户弹窗与当前用户信息

2026-10-25；D:\RPB；已与收银台直接操作一起提交并发布生产，功能版本608dfa54。

## 功能

- 点击商户钱包收银台标题，打开账户弹窗，可修改当前员工/管理员登录密码或退出当前员工会话。
- 两端复用账户弹窗外壳和只读身份展示组件。商户显示服务器当前会话的登录账号及姓名；顾客通过既有带storeId的顾客me接口显示姓名、手机号及已有邮箱。门店/经营主体仍单独展示。
- 打开时重新读取身份；失败可重试且禁止改密，关闭/切换门店后清理身份和密码，过期异步结果不会回填。商户会话与页面当前账号不一致时禁止改密。
- 商户与顾客分别调用各自密码及退出接口；商户退出失败保留当前登录状态，成功后清理员工状态并返回登录页。提交中阻止关闭和重复操作，中英文文案同步。

## 认证、API和数据库审查

- 在既有auth模块新增当前会话改密入口，职责分为Controller、Service及密码Repository；不调用管理员重置其他账号的接口，也不扩展钱包商业权限。
- 沿用商户6位字母数字、不区分大小写的登录规则；顾客原密码规则不变。校验旧密码、拒绝相同新密码，账号从RPB_SESSION解析，不接受账号或租户覆盖。
- 同源标记及Sec-Fetch-Site保护；账号锁内重新验证会话有效，密码哈希、撤销其他会话和无密码审计在一个事务中提交，当前会话到期时间不变。失败计数保留，连续5次错误暂停改密15分钟。
- 无迁移、环境变量或依赖变更；复用auth_accounts、auth_user_sessions及audit_logs。不会修改顾客密码、其他租户账号、角色、门店授权或钱包交易。
- 合约：docs/api/2026-10-25-account-self-password-contract.md。
