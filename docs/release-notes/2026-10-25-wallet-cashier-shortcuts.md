### 生产浏览器实际点击

使用现有已登录 Chrome 页签，实际验证：

1. 刷新收银台首页，显示“持卡与核销”和“酒水寄存卡”；重复的交易记录快捷卡片消失，底部交易记录保留。
2. 点击“持卡与核销”，直接进入当前门店 `/wallet/cards`，默认持卡与核销操作区已加载；点击返回后回到收银台。
3. 从首页点击“酒水寄存卡”，进入当前门店 `/wine-storage`；门店名称、寄存物品/申请/领取/记录页签加载完成。沿用寄存页现有返回链接可进入更多页。
4. 更多页无原来两个入口，其他管理入口正常；底部交易记录可以打开并读取历史交易列表。
5. 点击底部收银台回到首页，停留在消费收款页，未输入金额或提交任何业务操作。

浏览器连接有一次临时超时，恢复读取后页面正常；不是以 URL 返回 200 代替实际页面验证。本轮没有核销、寄存、收款、退款、修改真实业务开关或其他业务写入。
