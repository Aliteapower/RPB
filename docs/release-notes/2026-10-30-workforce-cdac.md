# Release Notes

## Version / Date
2026-10-30 · CDAC法定规则、适用设置与自动计薪。仅本地，未提交、推送或部署。

## New
- 管理中的“CPF／SDL／CDAC规则”新增CDAC工资档，维护生效月首日、结束月末日、工资上限、固定月缴额和官方来源，沿用规则版本、草稿、启停与历史。
- 2026/2027官方模板附带CDAC档次；现有规则可单独载入CDAC部分为待核对草稿。跨年复制调整日期并清空来源，须重新核对。
- 员工薪资方案新增适用、不适用、豁免及手动核对；资格由授权工资人员明确核对，不凭姓名推断。豁免、明确手工处理须有依据。
- 本月计薪核对可覆盖自动金额，必须填金额及说明；工资单显示基数、档次、标准额、实际额、模式和规则版本，管理说明不泄露给员工。

## Changed
- 按当前发薪公司实际月普通工资选CDAC档，不减员工CPF/其他扣款，不受CPF上限截断，报销不计入。零工资不扣；入离职月按实际工资选档，不再次按日数折算。
- 自动、豁免或不适用与手工CDAC项目并存时阻止确认，不能重复扣款或静默删项目。自动方案缺少生效CDAC规则也阻止确认。
- 旧规则、旧方案、旧核对输入及历史工资不回填、不重算。未设置的新字段省略null，原JSON来源指纹保持兼容。

## Fixed / Compatibility
- 旧客户端仅修改其他计薪输入时保留既有CDAC覆盖；回到自动须明确传cdacAutomatic=true，避免误清手工金额。保留输入版本、重放和既有确认守卫。
- 已配置方案不能通过旧方案占位项假装切回手工；需明确选manual并填写依据。旧客户端省略cdac字段仍保留现有设置。
- 计算用方案采用员工生日时仍保留付款和CDAC设置；已确认方案仍锁定，需新增生效方案。

## Migration
无新增数据库迁移、回填或新表。可选声明式字段存于原法定规则、方案及计薪JSON快照；CDAC标准和实际扣款纳入原cdac组件，继续使用原明细/汇总/CSV链路。

## Permission
法定规则仍仅租户总部管理员，校验所有相关授权门店与AppGate；个人方案/本月核对仍使用原公司工资授权。未新增Security路径或授权。员工只能读取本人已发布工资，不能看到豁免reference和手动覆盖note。

## Risk / Use
存量配置不会擅自启用。正式使用时，管理员应在对应有效规则中载入、核对并保存CDAC档次，再为员工创建或维护适用生效方案；已有手工CDAC须明确移除或保留manual。豁免必须由业务核实并留存相应依据，本功能不代为提交Opt-Out或申报缴费。

本阶段仍仅SGD普通工资；AW/AWS、其他自助团体、跨期补缴等未扩展。未进行真实申报、转账或生产压测。规则周期采用整月，与现有月度计薪模型一致。
