# Release Notes — 2026-10-24 顾客 PayNow 凭证

## New

顾客充值及账单 PayNow 补付可以拍照或从相册提交凭证，等待商户核对确认；支持 PNG/JPEG，最大 5MiB。商户可在原收款表单选择本单顾客凭证，核对银行 Ref 后明确确认到账。顾客完成或关闭后的单据保留本人凭证只读历史。

## Changed

复用前轮公共上传、OCR和钱包凭证捕获模块。提交只保存凭证及顾客付款声明，不改变余额、实收或账单支付状态。顾客记录不包含员工内部备注或员工附件。

## Migration / Permission

V070 附加凭证来源顾客、同租户外键及待确认索引；不重写 V069。员工沿用 `wallet.collection.confirm`，顾客必须通过顾客会话、原门店/单据及钱包归属校验，图片 private/no-store；写请求沿用钱包同源保护。商业过期出码规则不放宽。

## Validation / Risk

本地指针 PG 及相关后端 53/53、前端 124/124、生产构建通过。独立审查发现的完成后历史入口缺口已按 RED→GREEN 回归修复。未验证真实移动浏览器、真实银行图片识别准确率及生产运行；识别仅辅助，商户仍须核实银行入账。详见验收文档 `docs/development/WALLET_CUSTOMER_PAYNOW_PROOF_ACCEPTANCE_20261024.md`。

## Rollback Notes

本轮未提交或部署。后续交付需同时包含前轮 V069、本轮 V070 及对应前后端；回退应用保留新增表列、附件和审计历史，不能还原旧数据库覆盖资金记录。预订、排队、入座、清洁流程无变化。
