# 员工考勤：多段休息与异常核准

## New

- 共享规则模板，班次显式启用并复制快照；多段固定休息、实际休息、累计额度及是否计薪/是否休息打卡分别设置。
- 迟到/早退宽限、异常名称启停、全勤资格影响；缺卡先待核准，管理员明确确认或豁免并保留说明。
- 管理子页面统一返回管理及面包屑，保留门店和公司上下文。

## Changed / Fixed

- 既有打卡、出勤、核准页面复用休息摘要；未知结果重试保留完整请求，已批准记录再次核准不丢判定。
- 计划与实际区间不重复扣除，actual/quota不虚构标准休息；新规则摘要不再显示旧“无休息”。

## Validation

前端135项、相关后端138项及本地浏览器/API验证通过，构建通过。原135条基线记录字段及4个来源指纹保持不变。

## Migration / Permission

追加V098规则模板和nullable事实/判定字段，仅应用本地验收schema。权限沿用AppGate及租户/门店边界，未增角色，不自动修改工资金额或迁移旧排班。

## Risk / Rollback

模板按相对班次开始时间平移，需核对实际时钟；计划工时不代替合规判断。回退保留数据与审计，旧包不能直接处理已有新规则排班，须先暂停新规则写入并制定兼容方案。
