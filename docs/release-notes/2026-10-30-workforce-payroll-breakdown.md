# Release Notes

## Version / Date
2026-10-30 · 工资分类、付款资料与汇总演算。本地实现，未提交、推送或部署。

## New
- 既有模板、个人方案、本月调整支持额外普通工资、现金住宿津贴与已确认CDAC，自定义项目名称/金额和增删方式不变。
- 工资单与汇总按收入、员工扣项、雇主费用分开；报销独立，项目明细可展开。公司/员工CSV追加分类列；新增项目CSV含员工CPF、雇主CPF及个人SDL。
- 薪资方案可维护计划付款方式和收款银行；实际付款记录独立保存方式、银行、交易参考号，支持PayNow。旧未设置资料继续显示未知。

## Changed
展示从冻结快照直接投影，不重算或改写已确认金额；工资确认、发布、付款、冲正、权限和公司/门店/AppGate边界保持。旧JSON无payment字段时省略null，不引起来源哈希变化。新银行付款须填银行；老付款原样重试与冲正仍兼容。

## Fixed
- 现金住宿及额外普通工资纳入普通工资、CPF/SDL基数；扣项不降低基数，雇主费用不扣员工实发。
- 读取员工资料生日时，计算用方案保留计划付款资料，避免构造新方案对象时漏字段。
- 区分个人精度SDL及公司取整SDL；个人成本明确为估算，公司最终成本引用原批次总额。

## Migration
V102增加可空bank字段，扩展付款method约束。无回填、金额更新、删除或授权变化。仅在指针数据库端口61644的独立验收schema运行；未操作其他本地schema或生产库。

## Permission
复用既有工资公司授权、所有涉及门店和AppGate检查；没有扩大Security路径。员工仅能查看本人已发布工资，普通经理或其他公司的工资经理不能读取未授权工资。实际付款仍受本人、批次状态、余额、冲正及幂等限制，只登记不转账。
