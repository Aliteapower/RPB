# 顾客持卡二维码（2026-10-26，已发布）

## 行为

- 顾客持卡列表中，次数卡、周期卡、集次卡和奖励卡右上角提供二维码入口。失效或无今日额度的卡不可出码。
- 顾客确认本次数量后生成 120 秒一次性授权。商户在卡业务中点击“扫描顾客卡码”，按本次授权执行核销或集次。完成后顾客弹窗清除二维码，刷新卡权益。
- 集次仅允许一次；其他卡按确认数量扣除。过期码需手动重新生成，关闭弹窗不会撤销仍有效的授权。
- 原商户出码、顾客扫码确认流程继续可用。新增接口契约见 `docs/api/2026-10-26-card-presentation-contract.md`。

## 边界与风险

- 复用卡模块的事务、持有人校验、tenant/store 查询边界、App Gate、冻结时区、额度与幂等机制；核销记录保留实际扫码商户身份。
- 顾客创建的授权必须由商户执行，不能通过顾客确认接口自行集次或扣次。
- 无数据库迁移，无新增权限；商户集次需要 `wallet.cards.stamp`，消费需要 `wallet.cards.redeem`。
