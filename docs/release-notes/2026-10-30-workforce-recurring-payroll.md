# 长期薪资与月度自动生成第一阶段

版本：2026-10-30本地未提交工作区；项目D:\RPB。未推送、未部署。

## New

- 长期个人方案支持按核准出勤自动生成和自由员工全额月薪；原人工方式保留。
- 月薪工作周、标准日工时配置一次，后续按月份重新生成计薪单位。
- 自由员工有效雇佣月份全额基本工资，月中入离职及无薪假不折算；无出勤也不要求无来源人工说明。
- 固定收入项目可选择全额或随月薪计薪比例折算；新固定项目默认全额。

## Changed

含自动方案的工资批次创建时生成预览。月度页面只需编辑当月变动，免重复填写自动日数及核定说明；异常和特殊日人工待遇说明仍须处理。一次性奖金、报销及扣款不自动带到下月。共享模板更新不联动覆盖个人方案，已确认工资保持冻结。

## Fixed

自动计算的依据标记与管理员审批说明分开，系统生成不能充当特殊日人工说明。切换固定收入类别继续使用全额默认值。

## Migration / Permission

无数据库迁移、不回填或改写历史快照。既有JSON增加可选字段，旧字段缺省保持旧行为；原租户/公司/门店权限、AppGate、CSRF、命令重放及审计事务不变。预约、钱包、排队、入座及清洁业务未修改。

## Validation / Risk

详细命令、证据与结果见[开发验证记录](../development/WORKFORCE_RECURRING_PAYROLL_20261030.md)。普通自动方案需要明确的工作日口径和完整核准来源；月中调薪及特殊待遇不猜测金额。旧方案不会自动迁移，需要管理员一次选择长期生成方式。

本轮不实现定位打卡/岗位默认、共享模板批量升级、条件项目编排、并行/缩锁或增量重算。没有人数压测或真实设备验收。前端广泛回归存在已在原源码副本复现的10项基线失败，未扩大修复。

## Rollback Notes

旧计算包不理解generation/proration，不能直接用于已采用新方案的月份。若需回退，先暂停相关工资写入，保留新方案及冻结工资，准备兼容新字段的处理方式；禁止清除历史或重新折算已确认自由工资。生产变更须另行授权。
