# 存取酒模式（本地实现，2026-10-27）

## 新增

存酒管理页新增“存取酒模式”，租户管理员按门店选择：顾客核销（默认）或租户直接登记。直接登记时门店确认顾客、酒品及瓶数后登记收存、交付，顾客无需扫码核销；顾客仍能查询记录。直接取酒须明确确认实物已交付，确认后扣减库存。

## 兼容及权限

保留现有商户代存、顾客核销及旧单收尾。只有新请求使用当前模式，不修改历史存酒规则或既有授权。配置复用 wine_storage.rules.manage，限 tenant_admin 且产品开启；办理取酒沿用 wine_storage.deliver，关闭产品后仍可受控领取历史有效存酒。新增两个精确的本地 POST allowlist，无通配扩大。

## 数据迁移

V084 创建门店设置及设置审计表。未配置时默认顾客核销，不回填、不修改历史记录。实际启动新后端前需正常执行 Flyway 迁移。

## 验证

最终后端 40 项、前端 52 项通过；vue-tsc / Vite 构建与 diff 检查通过。覆盖默认模式、权限、租户门店隔离、幂等、旧单授权、过期、整批回滚及并发库存保护。详情见 docs/development/STORAGE_OPERATION_MODE_20261027.md。
