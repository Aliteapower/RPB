# Release Notes

## Version / Date

2026-10-30 workforce template governance阶段2A，本地实现交接；未提交、推送或部署。阶段2B界面由独立报告验收。

## New

- 门店派生、员工个人方案和月度金额变更申请；提交后固定完整内容，撤回后新增修订，租户总部显式批准或驳回。
- 批准的方案、门店版本、稳定月度记录及完整证明同事务保存；重试不能重复生效。来源变化显示过期，审计失败整体回滚。
- 影响预览复用原工资计算器，未知净额显示未知；未来固定月薪估计标明在职与合同假设。

## Changed

- 门店采用支持未来生效日期；当前候选按日期解析，版本号只用于并发。模板库返回未来计划；存在未来计划时无日期直接采用返回409。
- 个人/月度保持独立工资权限，无须额外员工管理权限；仅员工管理权不能查看个人工资申请。

## Fixed

保留旧个人方案或月度子项时不得静默更新来源基线。PR证件删除、日期变化、方案或输入版本变化须明确重建完整提案，旧修订及证明保持不变。

## Migration

V109新增申请、不可变修订/事件/命令/证明及稳定月度版本，另给门店采用新增effective_from。旧采用日期默认最早日，既有工资与付款JSON不重写。没有修改V108。

## Permission

所有接口保留有效门店App Gate及tenant/company/employee来源约束。个人/月度使用PayrollAccess；门店派生要求门店管理及当前公司；approve/reject额外要求租户总部。PUT保留同源及X-RPB-Workforce保护，响应private,no-store。

## Risk

阶段3仍须闭合旧金额写入口并让正式计算读取批准月度记录；本阶段不可单独宣称全链路金额审批完成。奖金/AWS/AW/跨期补缴财务内核属阶段5/6。对预约、排队、Walk-in、Seating、Cleaning无业务变更。测试依据见阶段2实施记录；没有真实银行、CPF平台或生产验收。

## Rollback Notes

当前仅本地，尚无生产回滚操作。若后续部署需回退应用，应先停用新增申请入口并确认兼容的读取路径；保留V109申请和审批证据，不删除已批准记录或恢复旧工资JSON。迁移为增量，禁止以删表或批量重写历史工资作为常规应用回退步骤。正式发布与回滚执行须另有明确授权。
