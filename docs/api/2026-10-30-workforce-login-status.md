# 员工绑定账号启停修复契约

范围：D:\RPB。先独立提交部署本修复；后续薪资方案改动不纳入。

员工可用状态与账号登录状态独立，保存员工档案、改密均不自动启用账号。新增 PUT /api/v1/stores/{storeId}/workforce/employees/{id}/login-account/status，请求 expectedVersion（非负）、status（active/disabled）。返回既有 Account 元数据并增加 canChangeStatus。

沿用 AppGate、员工完整可编辑范围、账号全部门店范围、本人/总部及管理员等级保护。只允许专用员工账号（workforce.view、store_staff、无其他产品配置）在此启停；共用账号显示受限原因，由原账号管理入口处理，避免影响其他产品。拥有改密权不自动拥有共用账号启停权。GET不写入。

认证模块更新账号状态及版本，并撤销原会话；不改密码、角色、权限、员工档案或考勤工资历史。锁员工后锁账号，同事务审计。版本相同且目标状态相同直接返回；版本恰好+1且状态相同为成功重试，无重复审计；其他旧版本409。格式400、越权403、缺失404；沿用EndpointSupport身份、写保护、no-store及精确本地安全路径。

测试：停用拒绝认证→显式启用可认证→停用撤销会话并拒绝认证；密码/权限/员工可用状态不变；重复/过期/审计回滚；共用/本人/越级/不完整门店/跨租户/AppGate拒绝；UI启停与员工草稿独立保存、失败刷新重试及受限状态。
