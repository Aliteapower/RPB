# 交易记录分类与收支筛选

统一交易列表保留。顾客首页的钱包、积分入口分别使用 category=money、category=points，下方入口及底部交易记录使用 category=all。顾客页签为全部/钱包/积分；商户保留消费/充值/积分页签。每类支持全部/收入/支出及原日期/类型/状态/门店/顾客/编号条件。高级条件折叠展示，当前分类仅展示对应统计。

GET transactions 支持 category=auto|consumption|topup|money|points|all、direction=all|in|out。未带 category 的 API 请求仍按 all 兼容；UI 保留显式 all，不再转换为 auto；auto 根据类型及当前权限选择可读类别。响应 category 为实际查询分类。money 包含 bill/topup/refund/money_reversal，不含 points，允许 type=all|payment|topup|refund|reversal；无任何资金来源权限返回403，不相容类型返回400。消费包含原消费及原消费退款；充值包含充值、充值退款和赠送权益冲正；积分包含钱包积分增加/扣减/兑换/双向冲正。退款/冲正不脱离原分类，详情/原单关联不变。

商户资金收支：消费收款、充值实收为收入，退款为支出，赠送权益冲正按权益支出（不计为现金退款）。顾客资金方向：消费支出、充值入账、消费退款收入、充值退出支出；积分按真实after-before增减。未记账/已取消保持业务预计方向，但明确未入账，不计已完成汇总。资金方向不是把本金赠送当现金总收入，仍保留各自统计。

分类、方向条件在后端同一只读查询/分页/完整汇总中执行，游标绑定分类和方向，不能跨条件重用。权限/租户/门店/本人范围始终相交。具体类别与不相容type组合400；无相应来源权限403。UI切换页签保留日期、门店等条件，清除不适用type及cursor；切换收支清除cursor。URL保留分类/方向，详情返回可恢复。

无需数据库迁移，不新增账本/操作API；原资金、积分、营销、付款授权和幂等不变。
