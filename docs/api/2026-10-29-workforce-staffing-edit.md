# 员工名单直接调整当天排班

名单GET /schedule-staffing/employees保持原参数/计数/门店隔离，items增量返回schedules:[{id,startAt,endAt,timezone}]，仅当前门店、该员工、工作日期及所选shiftId的有效未删除记录，按开始时间/id排序。仍按员工/日期去重列表及统计。同一班次同日多段保留全部时段ID，不随意选一条。

点击员工姓名：一个时段直接打开原ScheduleDialog，多时段先明确选择时间；原名单弹窗保留，编辑弹窗覆盖其上。原有PUT /schedule/{id}、版本/冲突、已打卡保护、取消/删除规则全部沿用，不新增写接口/权限/迁移。名单中的ID不能绕过写入时的租户、门店和管理权限校验。

成功保存/取消/删除后关闭编辑弹窗，重新读取名单，通知父页面按已应用区间/岗位/姓名/页码刷新排班表与统计，恢复原横向滚动。修改使记录离开当前班次/日期/筛选时从名单移除；末页移空自动退到最后有效页。失败保留编辑弹窗，名单不提前改变；取消编辑不刷新数据。编辑未结束/结果未确定时禁止关闭底层名单，沿用原命令恢复逻辑。

验证：真实ID与时段返回、多段选择、单条直接编辑、成功后名单/统计/表格同步、班次/日期变化/取消删除移出、末页回退、冲突/已打卡保护、跨店拒绝、关闭取消不写入、不重复实现保存逻辑。
