# 班次人数与同店同步契约

GET /api/v1/stores/{storeId}/workforce/schedule-board 增量返回 staffing:{shifts:[{shiftId,name,people,personDays}],days:[{shiftId,date,people}]}。沿用周一周视图/自然月视图、岗位和姓名筛选。统计覆盖筛选后的整个门店日期区间，不受员工分页影响；只统计scheduled且未删除记录。每日每班次人数按employee_id去重，区间people按员工去重、personDays按员工/日期去重；同一员工跨班分别计入相应班次。历史班次按shift_id归组、名称取区间内最近有效快照，不受模板更名影响。

管理员和有该店管理权限的经理访问同店同区间时读取同一数据；任一方复制成功后对方下次读取立即可见。前端可见且未编辑时每15秒静默刷新，窗口聚焦/从后台返回时也检查。保留查询已应用的筛选、日期、页码和表格滚动；保存/取消/恢复/删除/复制后更新统计。后台请求过期、切店、手动查询或弹窗打开后不得覆盖当前数据。401/403时清空旧表和统计并提示无权限；网络错误保留上次内容并提示同步失败。

不新增数据表、迁移或权限。统计及周/月表/复制来源/目标/回执均限定tenant_id+store_id。经理仅能操作已有授权管理门店，不能通过URL或他店预览指纹写入另一店。管理员切店是显式操作，复制源和目标仍在当前同一门店。复制不包含取消和删除记录。

验证：全店非分页统计、每日/区间去重、岗位/姓名与日期范围、取消/删除排除、跨租户/门店隔离、管理员→经理与经理→管理员复制可见、跨店预览/提交及回执重放拒绝、静默同步/暂停编辑/过期请求保护/解绑监听器/权限收回清空。
