# 员工名单证件提醒

GET `/api/v1/stores/{storeId}/workforce/document-expiries/employees?employeeIds={uuid,...}&days=30`，employeeIds必填1..100个UUID、去重，days默认30（1..365）。返回`{storeId,timezone,today,days,items:[{employeeId,due,expired}]}`，仅包含有提醒的已授权员工；零提醒用缺失分组表示。一次批量查询当前员工页，不为每行发请求、不携带证件号码、备注或附件。

复用既有证件到期日期/门店时区/完整员工管理权限与共享SQL范围；员工用户403，部分管理或跨租户/当前门店无关系的ID不返回分组，不泄露计数。空ID/超过100/非法参数400，private/no-store。无写入、迁移或新增权限。

既有GET `/document-expiries`增加可选employeeId过滤，仅在原tenant/store/完整管理权限内进一步缩小查询，不改变未传参数的旧行为。计数、列表及分页均限该员工，日期和删除规则不变。

员工列表显示默认30天即将到期及已过期数量。部分权限行不显示私有证件信息；读取失败明确提示，不伪装成无提醒。点击标识打开该员工及状态的证件列表，选择对应证件后复用维护弹窗。保存/上传/删除刷新员工标识与证件列表，保留员工页码；未知上传结果沿用原关闭保护及原命令重试。

验证：批量分组准确、日期边界、无提醒/部分权限/跨店/跨租户/员工/AppGate拒绝、100人范围校验、单员工过滤及分页、私有API及GET白名单、员工列表一页一批/翻页/过期响应/失败/弹窗维护刷新、原到期管理页回归。
