# 满勤待遇测算与月津贴实施计划

> 使用 executing-plans 按项实施。用户已批准上述方案并要求落地，不新增审批节点。

目标：薪资方案第三步核对即可按目标月份满勤测算到手，常用月津贴快捷添加；实际全勤奖依据核准资格发放，旧工资不改。
架构：新增只读估算应用服务/DTO/controller，复用PayCalculator、StatutoryCalculator、CdacPayroll。只处理完整月OW假设，不读取实际工资或产生结薪/审批记录。复用公共面板与三组明细。

- [x] 后端测试先行：月薪/时薪/日薪、固定津贴/住宿/全勤、缺政策/身份、员工范围、无写入；实际全勤 eligible/ineligible/pending/deferred及旧兼容。
- [x] 实现专用满勤估算API与模块；公司SDL单人精度单独标注，非权威公司汇总。选择月份，显式满勤天数/每日工时，无排班规则不猜天数；无加班、请假或临时项目。
- [x] 复用普通OW项目新增ow_attendance类别，来源保存核准全勤资格；月底前分段暂不结月奖；月底资格未知阻断，已知不符为0，符合按配置。既有快照不改；禁止人工月度补项伪造该类别。
- [x] 前端核对步嵌入测算组件；常用职务/现金住宿/全勤/其他津贴快捷添加，复杂分类折算按需；变更任何假设即清空陈旧结果。
- [x] 定向Java/PG/API/安全、前端交互与构建；独立审查必要范围一次；本地合成登录桌面/手机检查并更新发布说明。未验证视觉如实报告；不提交/不部署。
