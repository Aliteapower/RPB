# 统一证件维护弹窗

仅整理现有前端，不增加接口、数据库或权限，不部署。沿用受权Blob预览、原上传/识别及版本保存；保留已有改动。

- EmployeeDocuments保留证件列表与启动入口；新增、编辑、预览和重新识别都打开一个统一native dialog。上传入口和附件切换位于弹窗内，原图与可修正字段桌面并列、窄屏上下。
- 新增轻量DocumentEditorDialog只负责模态生命周期、标题、关闭与忙碌防关闭，不承载业务；复用现有预览/识别组件和EmployeeDocuments状态。
- DocumentMaintenanceDialog改为相同编辑器的入口适配，提醒页不再叠套第二个dialog。保留提醒保存后刷新计数的行为；员工页保存后关闭弹窗并刷新证件列表。
- 保存/上传/识别或上传结果未知期间阻止关闭与Esc；普通取消只丢弃未保存字段，已上传附件保留。切员工/门店强制清空旧上下文、回收预览URL并忽略迟到响应。
