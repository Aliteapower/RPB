# 储值钱包抢券活动实施计划

依据本聊天确认的最终方案，在持卡与核销工作台交付免费代金券和产品券。

- 数据层新增活动、规则版本、领取记录。活动锁串行化编辑、启停及发券，活动内 IP 唯一。单券锁串行化核销。
- 管理接口使用 /api/v1/stores/{storeId}/wallet/cards/voucher-campaigns，按现有卡业务门店和权限边界检查。GET 列表，POST 新增，PUT 更新，POST 状态切换，DELETE 删除未领取活动。
- 公开接口使用 /api/v1/public/voucher-campaigns/{id}，GET 查看，POST /claims 领取。浏览器凭独立随机凭证恢复，公开请求不读取认证会话。领取结果区分成功、已领取、活动状态和领完。
- POST /api/v1/stores/{storeId}/wallet/cards/vouchers/redeem，仅租户管理员在适用门店操作。服务端返回核销成功、已使用、未生效或已过期。
- 工作台复用卡方案布局，独立活动编辑器。公开页生成券码及可下载图片，现有扫码台识别新类型。
- 本地 PostgreSQL 测试先覆盖最后一张、同 IP、复扫、产品券快照，再执行前端构建和回归测试。保留生产状态。

## 接口与运行边界

- 管理列表返回活动状态、时间和三个计数，详情返回当前券面。更新、切换状态和删除携带活动版本，遇到旧版本返回 409。已发放券依据发行时的券面版本核销，活动归档保留记录。
- 匿名查看及领取可携带 X-Voucher-Receipt，值为当前浏览器生成并保存的随机 UUID。重复提交同一凭证恢复原券，同 IP 的其他凭证仅收到已领取状态。公开返回内容禁止缓存。
- 核销码使用 VC. 前缀，扫码台仅将格式符合的凭证提交本租户门店接口。未登录返回 401，权限和非适用门店返回 403，不存在及跨租户的券码返回 404。已使用和过期属于正常扫码结果。
- 客户端连接地址以服务端收到的 TCP 对端为准。未来通过反向代理开放时，用 rpb.vouchers.trusted-proxies 显式配置受信任的代理地址。代理须覆盖 X-Real-IP，确保来自客户端的同名头不会传到后端。本地直连无需配置。
- 新迁移 V137 预留在主工作区已有 V129–V136 之后。管理员操作沿用储值钱包 App Gate，发券还检查活动所属门店的储值钱包及卡功能状态。

## 分享与核销提示

公开分享二维码编码活动链接。管理端和公开页分享同一活动地址，领取凭证和单张券的核销码不参与分享。
扫码响应增加 batchCode 和 redeemedAt。batchCode 取四位活动代码。成功和复扫返回首次核销时间，未生效和过期返回空时间。现有核销事务和状态码保持原规则。
- 分享入口默认使用 RPB 公共入口域名。本地手机验收可用 VITE_VOUCHER_PUBLIC_ORIGIN 指向局域网测试入口。浏览器支持系统分享时可直接转发，也可复制链接或下载二维码。
- 领取和扫码结果使用可关闭的单弹窗。首次打开已领完或已结束的活动也弹出对应提示。复扫显示原始批次号和活动时区的首次核销时间，精确到秒。

## 发行总量和核销序号

扫码响应增加 issueTotal 和 redemptionNumber。首次核销在同一事务递增活动核销计数，并将结果及当时发行总量写入单券记录。复扫读取原记录。V138 用历史核销时间为已核销券补序号，时间相同按券码哈希固定排序，历史总量使用迁移时的活动发行总量。

## 再次扫描活动链接

公开活动 GET 和领取 POST 使用同一来源 IP 解析。活动可领或已领完时，已领取的来源 IP 打开链接返回 already_claimed，已持有领取凭证的浏览器可恢复原券。重复打开弹窗提示「你已领取1张，成功走起！」。跨浏览器仅凭同 IP 无法读取券码。

## 活动券统计

GET /api/v1/stores/{storeId}/wallet/cards/voucher-campaign-report 支持 query（活动名称或四位批次号）、kind（cash/product）和 page（从 0 开始）。返回每页 20 个归属当前门店的活动及 hasNext。权限沿用活动管理读取权限，停用卡功能时仍可查询历史。发行总量取当前活动配置，已领取和已核销取活动计数，过期按已领取的各券规则版本和时区统计未核销券。

## 核销登记号与分享批号

登记号由四位活动批号、首次核销时的发行总量和点号后的核销序号拼接。批号 4723、发行 10 张、第 1 张核销显示 472310.1。原批号、发行量、核销序号和时间仍独立展示。匿名活动响应包含四位批号，分享弹窗及下载的二维码图片显示批号，二维码内容仍是原活动地址。
