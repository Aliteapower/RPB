# 顾客存酒与钱包入口隔离

仅开通存酒时，不显示返回钱包。存酒home响应追加walletEnabled，取当前租户/门店wallet的AppGate商业判定；缺字段、未加载、错误均隐藏，不凭存酒权限推断钱包权限，复用原30秒刷新。

钱包customerContext在身份与门店校验后，针对无本人历史账户的顾客核验是否曾在本店开通钱包；未开通返回403/WALLET_PRODUCT_UNAVAILABLE。现存本人历史账户或既有开通过的门店保留原只读接口，不写订阅/账户。钱包产品停用/到期时，普通首页只显示不可用说明与显式历史入口，不挂载余额、积分、卡、充值等业务面板；历史路由继续原授权。共享顾客注册、激活、忘记密码不能被钱包商业开关阻断。

按顺序：先补存酒返回链接、钱包受限视图与后端无开通拒绝的失败用例；实现最小AppGate/DTO/界面改动；关联Node与Java/PostgreSQL回归、类型构建、桌面和窄屏合成验收。复用产品入口技能、共用页头与现有模块样式，不更改真实订阅或无关工作区文件。必要发布使用本聊天既有授权，制品和生产状态现场重验。
