# 钱包风格顾客管理与公共顾客能力

1. 公共 customers 模块持有查询、新增、编辑、归档、校验、异步范围隔离；复用当前 tenant-admin API，不增加数据源。
2. 平台顾客表单字段复用，租户后台保留原管理外壳，钱包新增自己的卡片列表／独立编辑状态。
3. 钱包入口改到 wallet/customers，保留返回充值与积分的固定来源参数；旧租户后台页面仍为通用入口。
4. 管理权限和租户／门店边界不变，进入顾客管理不创建资金或积分账户。
5. 测试覆盖两种外壳、同一 API 与同一顾客 ID、重复手机、权限、重复保存、切店竞态、移动布局、原有钱包回归。
6. 本地运行仅使用 target/local-postgres-current.txt 指向的 PostgreSQL，隔离 schema 验证。本轮不提交、不推送、不部署。
7. 按追加需求，新增时默认勾选 PDPA，取消勾选不能保存；平台后台／钱包共享表单及后端校验，保存实际来源、操作者、时间与版本，不补造历史同意。
8. 顾客可通过平台通用注册页或钱包注册页自行注册，商户可展示链接／二维码；只创建新手机号档案，不认领已有档案。沿用既有手机号后六位初始密码和修改密码流程，不接短信，不自动开资金账户。
