# CPF/SDL年度规则与管理去重

用户明确授权实现，保留已有工作和数据，不部署。截图第3项仅删除重复局部导航，不删除岗位功能。

1. 核对CPF 2026/2027官方五表、工资档公式、生日/SPR周年次月、OW上限和SDL汇总舍入。
2. 新增statutory政策值对象与校验、官方可载入模板、租户政策header及不可变revision仓储、应用服务和窄API。一套生效政策内维护5表×年龄档、工资档/公式参数/SDL/舍入，非表达式执行。
3. 计算器接收明确政策配置，生产工资来源按月份解析数据库启用版本。无政策或重叠失败关闭。捕获政策完整快照、员工资料DOB（优先于旧个人方案DOB）和对应版本；已锁定工资单不重写。
4. 迁移仅新增政策表，不自动启用权限。当前本地验收租户由管理员载入2026初始政策以保持旧行为；新租户需明确配置。所有计算来源均引用完整政策ID/version/config；旧锁定快照保留，可能提示来源变化但不会改账。
5. 管理增加一个统一CPF/SDL页面及共享配置编辑器；移除首页公司下拉、将授权公司选择保留在工资模板/个人方案列表；统一去重已由共享导航覆盖的局部“管理/当前页”条。
6. 测试官方边界、修订与生效、范围/权限/AppGate、重放/审计回滚、年龄/生日、无配置阻断、历史快照/政策身份指纹；构建和真实本地页面验证，记录发布说明。不扩AW/奖金或跨期补缴，不扩多币。
