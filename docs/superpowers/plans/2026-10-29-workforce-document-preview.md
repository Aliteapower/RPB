# 员工证件上传与原图对照

在现有EmployeeDocuments内实施，不新增业务页面，不部署，保留已有改动。

1. 新增/编辑表单直接显示上传入口，先选类型即可上传。新证件上传时以同一UUID建立仅类型的空记录，再上传附件；个人字段与OCR候选只有用户点击保存才写入。若取消编辑，已上传附件仍保留在证件列表，不自动删除。创建网络重试复用UUID/相同空命令，避免重复。
2. 预览复用已有受权GET附件接口，以same-origin/no-store获取Blob；仅JPEG/PNG/WebP/PDF可展示，无新增公开URL、权限或后台端点。对象URL随关闭、源切换、门店/员工切换和卸载清理；旧异步响应不得污染新上下文。
3. 原图预览与OCR建议/编辑表单桌面并列、窄屏上下显示。图片可放大/适应，PDF内嵌预览有下载后备。显示的是实际上传保存的压缩附件，不声称保存了压缩前照片。
4. OCR建议增加可修正输入，修正/明确选择后填入同一证件表单，仍须保存。批准日期与正式PR日期维持区别；不自动改变员工身份、工资或旧记录。
5. 测试先覆盖新增表单入口、空记录创建/上传版本、未保存字段不提前写入、对照修正保存、预览鉴权/MIME、URL释放/迟到结果及既有OCR/工资回归；构建和本地真实浏览器操作；原业务逐行哈希验证。

后端与数据库保持现状，下载接口Content-Disposition不修改。客户端Blob预览是可逆展示，现有下载、OCR及维护权限全部继续由服务器验证。
