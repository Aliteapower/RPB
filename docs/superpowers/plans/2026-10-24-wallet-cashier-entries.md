# 钱包收银台扫码与手机号入口

本轮实现并测试，不提交、推送或部署。保留原工作区。

1. 蓝色卡片内以消费收款／充值／积分页签选择扫码业务，权限决定可见业务；消费保持金额先行及当次扫码授权。
2. 下方卡片独立手机号入口，复用现有顾客查询；输入完整手机号，候选核对、明确确认后再选择充值或积分，不自动记账，不用于消费扣款。
3. 手机号选客仅页面状态，与扫码身份凭证分开。来源／门店切换清空顾客；操作提交时禁止切换，切换业务保留已确认顾客。
4. 复用原充值、营销、积分和权限模块；无新增 API 或迁移。先补行为测试，验证候选未确认、确认、下一位、切店、权限和原扫码回归，再构建与本地浏览器检查。
