# 商户存酒记录清晰度与密度

针对截图的商户/员工记录页，使用四个紧凑分类：存酒记录、取酒记录、酒品明细、操作日志。不改变顾客端、接口、库存、权限或数据库。

存酒摘要以核实后的名称和实收数量为主；待收存展示申请数量。申请和实收不同才默认提示差异，完整原申请、核实结果、照片和说明折叠保存。历史收存状态标为“已收存”，不冒充当前库存；当前余量独立在酒品明细中展示。经办人和保管人均有标签。

取酒以已取走/待领取/取消/过期区分；记录时间使用真实完成/创建/取消事件，不再用取酒码过期时间代替发起时间。缺失时间明确未记录。操作日志注明仅供追溯，不重复计算存取数量。现有纠错和补图权限保留，显式历史仍不可写。

先补不可变摘要与时间语义测试，再实施布局和挂载行为验证；干净归档构建及桌面/390/320合成验收后沿用本聊天已有发布授权，只发前端。
