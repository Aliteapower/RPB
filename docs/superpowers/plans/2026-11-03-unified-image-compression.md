# 全站图片上传前统一压缩

所有网页图片上传在API multipart边界使用共享prepareImageFormData，逐张严格<=1,000,000字节；酒存、商户/顾客付款凭证及OCR、平台/租户品牌Logo/社交Logo、广告图片、员工证件图片统一接入。JPEG先调质量再等比缩小；PNG/WebP保留透明能力转PNG按需缩小；小图保持原文件，证件沿用强制去元数据/JPEG处理。上限只针对图片，PDF/视频/表格沿用原规则。已有历史图片不修改。

移除在压缩前以5/10MB拒绝大图的UI路径；保留80MiB输入及像素安全界限。图片选择和批量准备过程有busy与scope防迟到保护。压缩失败不得提交原大图；字段、权限、幂等键、所有者及既有后端验图规则不变。不引入全局fetch拦截、不改后端契约或存量资源。

验证共享算法和multipart实际边界、真实JPEG/透明PNG压缩输出、小图/超限/失败/资源释放、混合PDF视频不变、各API适配与组件异步竞态；相关现有测试和干净构建。只发布前端，保持无关工作区改动。
